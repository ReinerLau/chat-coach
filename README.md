# chat-coach

chat-coach 包含三个可独立使用的组件：

- **中文回复教练 Skill** 根据真实聊天提供示例回复。是否发送由你决定。
- **联系人记录 Skill** 保存联系人背景和互动。
- **微信历史 MCP** 只读查询本机微信历史。

## 使用中文回复教练 Skill

把联系人名写在 `$chat-reply` 后面。未指定回复方式时，默认使用“接话”预设。

```text
$chat-reply 小林
$chat-reply 小林 --preset 共情 --context "我已经回了她一句辛苦啦，想顺着加班的话题再接一句"
```

### 通用参数

联系人名必填，所有命名参数都放在联系人名之后，顺序不限。

| 选项 | 说明 |
| --- | --- |
| `<联系人名>` | 必填，紧跟 `$chat-reply`，指定本轮交流对象。 |
| `--context <说明>` | 非空；补充本轮近况、想法或限制，内容有空格时加引号；最多一次。 |
| `--preset <预设名>` | 选择下方对应意图列出的整套预设；最多一次，不能与 `--intent`、`--principle` 或 `--technique` 同用。 |
| `--intent <意图名>` | 一轮最多指定一个意图。单独指定时使用同名预设；与原则或技巧同用时只使用明确点名的组合。 |
| `--principle <原则名>` | 使用对应意图表中列出的原则；可重复填写不同原则。 |
| `--technique <技巧名>` | 使用对应意图表中列出的技巧；可重复填写不同技巧。 |

同一原则或技巧不要重复选择。只写原则或技巧时以“接话”预设为基础；需要其他意图时请同时写 `--intent`。未指定意图时默认“接话”。

### 按意图选择参数

意图说明本轮要完成的交流行为，一轮只选一个。预设会载入一套固定的意图、原则和技巧；自选组合时只使用表中该意图支持的原则和技巧。

#### 接话

根据对方待回复的内容继续交流；话题自然结束时不硬续。

##### 预设

| 选项 | 说明 |
| --- | --- |
| `--preset 接话` | 默认预设，用于回应对方当前内容。 |

##### 原则

| 选项 | 说明 |
| --- | --- |
| `--principle 先接内容` | 先处理对方实际说的内容、问题或约定。 |
| `--principle 事实有据` | 不把推测或旧计划说成确定事实。 |
| `--principle 尊重边界` | 对方拒绝或要求停止时收住。 |
| `--principle 把握分寸` | 按关系和回应幅度调整长度与亲近感。 |
| `--principle 不评价对方` | 不把推测写成对方的情绪或性格标签。 |

##### 技巧

| 选项 | 说明 |
| --- | --- |
| `--technique 行为聊法` | 先接对方内容，再说由此引出的具体行动兴趣。 |
| `--technique 扩大冲突` | 对方先轻度调侃时，顺着原话做一小步玩笑式反驳。 |
| `--technique 平衡` | 真实肯定后，接一个与当前事情相关的轻微转折。 |
| `--technique 状态感受切换法` | 从有依据的近况或状态，转到轻量的主观感受。 |
| `--technique 魔趣法则` | 借双方已有联系点，加入明显是假想的夸张动作。 |

#### 共情

回应对方具体的处境与感受。

##### 预设

| 选项 | 说明 |
| --- | --- |
| `--preset 共情` | 认真回应对方的处境与感受。 |
| `--preset 轻松共情` | 对方情绪较轻且双方能接玩笑时使用；须通过 `--preset` 明确选择。 |

##### 原则

| 选项 | 说明 |
| --- | --- |
| `--principle 非评价式共情` | 贴近具体处境回应，不只复述或评价情绪。 |
| `--principle 避免比较转移` | 不比惨，也不把话题转成自己的故事。 |
| `--principle 事实有据` | 不把推测或旧计划说成确定事实。 |
| `--principle 尊重边界` | 对方拒绝或要求停止时收住。 |
| `--principle 把握分寸` | 按关系和回应幅度调整长度与亲近感。 |
| `--principle 不评价对方` | 不把推测写成对方的情绪或性格标签。 |

##### 技巧

| 选项 | 说明 |
| --- | --- |
| `--technique 行为一致` | 有共同处境时，用共同动作表达站在同一边。 |
| `--technique 夸张引申` | 轻松且能开玩笑时，把同一情境夸张到明显不可能。 |

##### 原则

| 选项 | 说明 |
| --- | --- |
| `--principle 具体赞美` | 根据对方明确做过的事表达感谢或感受。 |
| `--principle 事实有据` | 不把推测或旧计划说成确定事实。 |
| `--principle 尊重边界` | 对方拒绝或要求停止时收住。 |

| `--principle 不评价对方` | 不把推测写成对方的情绪或性格标签。 |

##### 技巧

| 选项 | 说明 |
| --- | --- |
| `--technique 平衡` | 真实肯定后，接一个与当前事情相关的轻微转折。 |

#### 邀约

回应对方对线下见面邀约提出的顾虑。

##### 预设

| 选项 | 说明 |
| --- | --- |
| `--preset 邀约` | 回应对方对线下见面邀约提出的顾虑。 |

##### 原则

| 选项 | 说明 |
| --- | --- |
| `--principle 先理解顾虑` | 先理解对方对见面的具体担心，不催促。 |
| `--principle 事实有据` | 不把推测或旧计划说成确定事实。 |
| `--principle 尊重边界` | 对方拒绝或要求停止时收住。 |
| `--principle 把握分寸` | 按关系和回应幅度调整长度与亲近感。 |
| `--principle 不评价对方` | 不把推测写成对方的情绪或性格标签。 |

#### 起头

根据真实近况或近期互动主动开场。

##### 预设

| 选项 | 说明 |
| --- | --- |
| `--preset 起头` | 根据真实近况或近期互动主动开启交流。 |

##### 原则

| 选项 | 说明 |
| --- | --- |
| `--principle 事实有据` | 不把推测或旧计划说成确定事实。 |
| `--principle 尊重边界` | 对方拒绝或要求停止时收住。 |
| `--principle 把握分寸` | 按关系和回应幅度调整长度与亲近感。 |
| `--principle 不评价对方` | 不把推测写成对方的情绪或性格标签。 |

##### 技巧

| 选项 | 说明 |
| --- | --- |
| `--technique 平衡` | 真实肯定后，接一个与当前事情相关的轻微转折。 |
| `--technique 状态感受切换法` | 从有依据的近况或状态，转到轻量的主观感受。 |
| `--technique 魔趣法则` | 借双方已有联系点，加入明显是假想的夸张动作。 |

完整预设组成见[预设清单](skills/chat-reply/references/presets/index.md)。原则和技巧都必须符合当下场景；每条示例都应体现选定的技巧。无效的意图与原则/技巧组合会被拒绝。

例如，想自选共情的原则和技巧，可写：

```text
$chat-reply 小林 --intent 共情 --principle 非评价式共情 --technique 行为一致 --context "她说早上太冷不想起床，我们都在等公交"
```

“夸张引申”只用于共情；单独填写时不会把默认的“接话”改成共情。
旧参数 `--strategy`、`--mode`、`--preset 普通回应` 和把技巧名填在 `--preset` 后面都无效。

含义明确的自然语言调用也可以使用。完整输入规则见[中文回复教练 Skill](skills/chat-reply/SKILL.md)。

中文回复教练 Skill 只接受手动调用。普通聊天不会自动调用它。

## 使用联系人记录 Skill

用 `$contact-notes` 查看或维护联系人档案。

```text
$contact-notes 记一下小林的背景：我们是朋友介绍认识的，她在杭州工作。
$contact-notes 补充小林的互动：昨天线下吃饭，她说这两周准备考试，考完再约。
$contact-notes 修正小林的城市：之前记错了，她在上海。
$contact-notes 删除小林档案中关于城市的信息。
$contact-notes 查看小林的档案。
```

两个 Skill 都已安装时，联系人记录 Skill 也会在回复流程中保存新材料里的有用增量。普通聊天不触发自动记录。

以下内容不会写入档案：

- 示例回复、所选预设和模型推测。
- 你明确要求本轮或指定范围不记录的信息。

同轮显式调用两个 Skill 时，先完成指定的记录、修正或删除，再提供示例回复。细节见[自动记录说明](skills/chat-reply/references/auto-notes.md)。

每个联系人对应 `~/.chat-coach/contacts/` 中的一个 Markdown 文件。档案保存背景、当前情况、互动记录和个人观察。

微信历史按需查询，不复制全文到档案。ChatGPT 无法直接读取这些本机文件。

## 安装 Skill

两个 Skill 可以独立安装。用户级 Skill 放在 `~/.agents/skills/`，参见 [Codex 官方 Skill 说明](https://learn.chatgpt.com/docs/build-skills)。

1. 从仓库 `skills/` 中选择 `chat-reply`、`contact-notes` 或两者。
2. 将所选目录的全部受版本控制文件复制到 `~/.agents/skills/` 下的同名目录。
   - 保留 `SKILL.md`、`references/` 和 `agents/openai.yaml`。
   - 安装 `chat-reply` 时，还要保留 `scripts/selection.py`。
   - 无需复制仓库 `docs/`、另一个 Skill 或本机 `contacts` 软链。
3. 用 `$chat-reply` 或 `$contact-notes` 开始使用。新安装的 Skill 未显示时，重启 Codex。

- 只安装中文回复教练 Skill：可读取已有档案，但不自行写入。首次需要保存时，会提示安装联系人记录 Skill。
- 只安装联系人记录 Skill：可独立维护档案。

[微信历史 MCP](mcp-server/README.md) 供 MCP 客户端查找会话、分页读取本机微信历史。它不调用模型，也不发送微信消息。

安装、启动和 ChatGPT 接入步骤见 [MCP 使用说明](mcp-server/README.md)。
