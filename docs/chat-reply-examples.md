# 回复 Skill 的活人感举例

这份文档解释 [Chat Reply Skill](../skills/chat-reply/SKILL.md) 中的活人感：像普通真人在当前对话里会说的话。细节见 [自然表达参考](../skills/chat-reply/references/naturalness.md)，返回 [README](../README.md)。

下面都是虚构示例，“更像聊天”只适用于给出的语境。判断依据是表达，而不是礼貌程度、是否解决问题或聊天结果；同一个场景可以有多种自然说法。

| 要点 | 场景 | 更像聊天 / 应做 | 对照 | 说明 |
| --- | --- | --- | --- | --- |
| **1. 双方知道的事，话里不必重新交代** | 此前已确认周六搬家，对方来帮忙。对方问“几点过去？”，用户确定十点开始。 | **更像聊天：**<br><br>十点过来就行 | **像在写说明：**<br><br>因为我周六要搬家，你之前也说会来帮忙，所以你周六十点过来就行。 | 后者向聊天双方重新解释已知背景，像写给旁观者的说明。不是因为它长就不好，而是这些话放在这里不自然。 |
| **2. 长回复也可以有活人感** | 朋友问“你旅行回来啦？路上咋样，多讲点”。用户提供：火车晚点两小时、下车时下雨、行李箱轮子卡住，最后顺利到酒店。 | **更像聊天：**<br><br>别提了，火车晚了俩小时，下车还赶上下雨。拖着箱子走，轮子又卡住了，真是服了。反正最后到酒店了 | **像在写报告：**<br><br>本次旅途主要经历了三个问题：一是列车晚点，二是天气不佳，三是行李设备故障。总体而言，最终顺利抵达目的地。 | 两条都有依据。前者在讲经历，后者在归纳事项；活人感不是靠删到一句话获得的。 |
| **3. 情绪可以直接出现在回复里** | 对方说“至于吗，我才迟到四十分钟”。用户说自己等了四十分钟，非常生气，不想道歉。 | **更像聊天：**<br><br>四十分钟还叫才？我在这干等四十分钟，你还觉得没事是吧 | **像固定和解流程：**<br><br>我理解你可能有自己的原因，但我的感受同样值得被尊重，希望我们以后能够加强沟通。 | 前者表达了用户提供的情绪。是否会让矛盾升级不作为质量标准；后者的问题是抽象套话与当前说话状态脱节。 |
| **4. 可以自然猜测，不必先分析对方** | 对方说“忙一天了，刚下班”，用户想顺着聊。 | **更像聊天：**<br><br>累了吧，今天怎么忙成这样 | **像分析报告：**<br><br>从你的描述来看，你今天可能承受了较高的工作负荷，需要及时关注自己的身心状态。 | “累了吧”是试探，不是在确认某个未提供的具体经历。区别在表达方式，不要求所有日常猜测都先有证据。 |
| **5. 信息接住了，仍可以继续聊** | 两人刚一起看完电影，对方说“到家了”。用户想继续问对方怎么看结尾，还没有提供自己的评价。 | **更像聊天：**<br><br>刚那个结尾你看懂没 | **像模板过渡：**<br><br>很高兴你已顺利到家。接下来，我想进一步了解你对刚才电影结局的理解。 | 继续问电影不需要证明它对完成沟通有帮助；前者自然接着共同话题说，后者像流程说明。 |
| **6. 多个点不必按清单逐项接住** | 对方说“忙了一天，午饭都没吃。你到了没？”，用户已经到了。 | **更像聊天：**<br><br>到了到了，你直接过来吃吧 | **像在归纳原文：**<br><br>你今天工作繁忙，未能按时吃午饭。我已经到达，因此你可以前来与我会合。 | 也可以回“忙一天了？那你先过来吃”。不是只能处理一个动作，而是不用把每个背景都写成整理后的句子。 |
| **7. 口语化按语境来，不靠装饰** | 普通同事问“材料今天能发我吗？”，用户确定今天能发。 | **更像聊天：**<br><br>可以，今天发你 | **像在表演口语：**<br><br>啊这哈哈哈安排上了老铁，稳稳拿捏，包的呀 | 网络词、重复或省标点本身都不是坏表达，但在这段对话里成串出现，像为了“真人感”特意装饰。其他场景里完整正式的句子也可以自然。 |
| **8. 缺真实原因时，先问用户** | 对方问“你怎么不想去了？”。用户希望回复说明真实原因，但没有向助手提供原因。 | **此时助手向用户问：**<br><br>你不想去的原因是什么？ | **不应直接代写：**<br><br>今天加班太累了，改天我请你。 | 这不是对聊天结果的限制，而是用户事实尚未给出。问清后才能把用户自己的原因写进去；问题不是要发给聊天对方的话。 |
| **9. 不依赖缺失事实时，直接生成** | 对方问“周末出来吗？”。用户不想去，不要求解释原因。 | **可以直接给回复：**<br><br>这周末就不去了 | **不必先问用户：**<br><br>请补充拒绝原因、双方关系、期望达成的沟通效果以及后续安排。 | 这条回复无需原因就能成立。额外的调查会把普通回复请求变成问卷。 |
| **10. 候选不必交出不同策略** | 对方说“好，那明天下午见”，用户同意见面，想看三个说法。 | **都可以自然：**<br><br>行，明天见<br><br>好啊 明天见<br><br>那明天下午见 | — | 这些候选表达相近也成立。无需为了策略差异补上用户没提供的计划、承诺或新话题。 |
