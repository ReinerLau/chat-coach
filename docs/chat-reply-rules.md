# 中文回复教练 Skill 回复规则说明

本文供人阅读，说明 [中文回复教练 Skill](../skills/chat-reply/SKILL.md) 中的两条回复规则。Skill 不引用或读取本文，手工比较时也不把本文或示例加入模型输入。

示例取自现有手工测试场景，用于理解规则，不作为固定回复模板。正反例只说明各自场景中的差别，不把某个词或句式列为通用禁令。

## 规则 1：当前意愿

> 行动、表态和承诺以用户明确表达的当前意愿为依据。

适用于候选回复需要表达行动、表态或承诺的场景。判断依据是用户本轮明确表达的选择或倾向。

### 案例 03：本次不参加露营

场景来自 [周末露营](chat-reply-manual-tests.md#03-周末露营)。朋友正在订营位，问是否给用户留一个。

用户意图：这次不想去，想直接说不去，不需要解释原因。

| 类型 | 候选回复 |
| --- | --- |
| 正例 | 这次不去了，你们玩。 |
| 反例 | 这次不去了，你们玩，下次我一定去。 |

正例表达了本次不参加的选择。反例额外承诺了下次参加，但用户没有表达这个当前意愿。问题在于新增的承诺，不在于“一定”这个词本身。

## 规则 2：一个主要任务

> 候选回复只留一个主要任务。

适用于生成候选回复时判断哪些内容服务于本轮用户意图。主要任务应围绕用户意图理解，可以包含完成该意图所需的情绪、信息和安排。

### 案例 02：约三点见面

场景来自 [周六的咖啡店](chat-reply-manual-tests.md#02-周六的咖啡店)。朋友问几点到合适，两人已经说好在那家咖啡店见面。

用户意图：两点半之前有事，三点能到那家店，想约三点。

| 类型 | 候选回复 |
| --- | --- |
| 正例 | 三点吧，咱们店里见。 |
| 反例 | 三点吧，咱们店里见。你最近工作怎么样？暑假想去哪玩？ |

正例完成约时间的主要任务。反例在约时间之外又发起工作近况和暑假旅行两个话题，超出了本轮用户意图。这个对照不表示聊天中不能问近况或聊旅行；用户想聊这些时，任务判断也会随之变化。

### 案例 07：表达高兴并约吃饭

场景来自 [面试之后](chat-reply-manual-tests.md#07-面试之后)。朋友拿到了工作机会，想在今晚吃点好的。

用户意图：替朋友高兴，今晚七点以后有空，可以一起吃饭。

| 类型 | 候选回复 |
| --- | --- |
| 正例 | 太好了！我七点以后有空，一起吃？ |
| 反例 | 恭喜啊！ |

这组对照说明规则的边界。正例的高兴、空闲时间和吃饭邀请共同完成用户意图。反例把“一个主要任务”误解成只能表达一个意思，遗漏了吃饭安排。规则不要求只写一句话，也不要求删掉用户已经明确表达的组合意图。

## 本轮手工比较

两版使用相同的 Skill 结构，基线版临时移除回复规则 2、仅保留规则 1，实验版保留规则 1、2。

固定模型、测试输入和用户意图，每次使用新会话，仅调用 chat-reply；[手工测试集](chat-reply-manual-tests.md) 中的案例 01、02、04、05、07 每版各试三次。由用户判断自然度和信息完整性，重点检查案例 07 是否遗漏组合意图。

改善且无遗漏才保留规则 2，否则撤回规则 2。本轮不运行自动化回复评测，也不输出评测报告。
