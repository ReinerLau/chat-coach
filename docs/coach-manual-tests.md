# 教练 Skill 手工测试输入

```text
$coach 目前收录了哪些关系推进技巧？只列名称。
```

```text
$coach 介绍一下你已收录的技巧分别适合什么情况。不需要联系人背景，也不用写消息。
```

```text
$coach 我和小林上次一起逛过旧书店，她今天主动发来那家店周末夜场的消息。我想顺着这个机会自然地约她再去一次。从已收录技巧里推荐一个，给出具体使用要点，不写成品。
```

```text
$coach 请使用“具体邀约”这个技巧。我忘了它的使用要求，请先查已收录条目，再告诉我适用条件、具体做法和容易误用的地方。
```

```text
$coach 请使用“未收录技巧示例”。我只记得名字，请你按技巧库中的内容给出用法，不要凭印象补写。
```

```text
$coach 请收录“具体邀约”这个技巧。来源是我在这条消息中给出的说明：适用条件是双方仍愿意继续交流，且有真实的共同话题或活动；具体做法是提出一件明确、低压力的共同活动，并留下对方选择时间或拒绝的空间；容易误用之处是把一次积极聊天当成已经答应见面，或在明确拒绝后继续邀约。请按技巧库格式保存。
```

```text
$coach
我想顺着这段聊天邀请小林周末再去旧书店。请从已收录技巧中选一个并给出使用要点，不写可发送消息。
聊天记录：
我：上次那家旧书店还挺有意思的
小林：是呀，我看到它这周末还有夜场
```
