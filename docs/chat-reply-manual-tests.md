# 中文回复教练 Skill 手工测试集

01–24 均为原创虚构聊天。01–18 是独立场景；19–20、21–22、23–24 各为一组，组内最后一条消息相同，前文不同。25 是根据实际反馈追加的用户意图缺失回归案例，与 01 使用相同聊天记录，但没有“我的说明”。

首轮只测试新版中文回复教练 Skill。记录模型与 Skill 版本，每个场景使用新会话，只复制场景中的“测试输入”代码块，以 `$chat-reply` 显式调用。模型的回复、向用户提出的问题或解释均可原样保存在“原始输出”处，判断与备注由你填写。

**手工验收方法**

- 首轮应先简短询问用户意图，例如“你想接着跟他开个玩笑，还是也想一起去吃？”，等待回答后再生成候选回复。
- 在同一会话回答“只想接个玩笑”，检查候选回复是否符合该意图，且未添加下楼或占座安排。
- 用新会话重新测试本案例，在模型询问意图后回答“十分钟后下楼一起吃”，检查候选回复是否符合十分钟后的安排，且未重复确认已明确的用户意图。
- 对照案例 01：已有“一起去吃”的明确意图，应直接生成候选回复。
