# 中文回复教练 Skill 手工测试集

全部案例均为日常闲聊，双方通过聊天交换见闻、近况、感受或看法，没有需要共同完成的事情。“没有目标”指双方没有共同任务，用户仍可以说明本轮想表达的内容或态度。

01–24 均为原创虚构聊天。01–18 是独立场景；19–20、21–22、23–24 各为一组，组内最后一条消息相同，前文不同。25 保留根据实际反馈追加的用户意图缺失回归检查，与 01 使用相同聊天记录，但没有“我的说明”。26 保留根据实际反馈追加的复核回归检查，与 05 使用相同聊天记录，用户意图为感谢对方记住细节。

首轮只测试新版中文回复教练 Skill。记录模型与 Skill 版本，每个场景使用新会话，只复制场景中的“测试输入”代码块，以 `$chat-reply` 显式调用。模型的回复、向用户提出的问题或解释均可原样保存在“原始输出”处，判断与备注由你填写。

判断候选回复时，重点看是否承接具体话头、符合前文和用户意图、有活人感，是否擅自把闲聊推进成邀约、任务或行动安排。不设标准答案，也不以固定句式或字数判定。案例 16 保留必要事实缺失的检查；案例 25 保留用户意图缺失的检查，询问用户后再继续测试。

**手工验收方法**

- 使用新会话，只复制上面的“测试输入”代码块；不加入本文的验收说明、规则说明文档或示例，也不追加“请含蓄一点”等要求。
- 检查候选回复能否承接前文已经表达的喜欢，通过接话带出感动并完成感谢，省去仅用于解释已有表达的补充句，而不是把“喜欢”和“感动”逐项交代。
- 检查感受是否从具体接话中带出，是否额外补写了前文和接话已经足以传达的情绪自述或解释。
- 结合上下文判断逛街细节是否需要重申；不要求固定句式或字数，也不把直接说出情绪视为失败。
- 对照案例 03、07，确认能承接趣事和喜讯，未擅自添加一起出游或吃饭的安排；对照案例 13，确认个人看法没有被弱化；对照案例 06，确认用户想讲述经历时正常展开。
- 原始输出、判断与备注由用户记录，不代填测试结论。
