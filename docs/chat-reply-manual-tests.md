# 中文回复教练 Skill 手工测试集

01–24 使用不同交往阶段的女性一对一虚构聊天，观察首轮能否依据真实场景直接给出「态度、情绪、想法、分析」四字段输出，以及所有合适且有实质差异的方向和各自的示例回复。输入中的「我的说明」仅供理解场景，不要求照单拟写；「态度」只写六级标签之一或「无法定级」，不附依据；情绪或想法没有可靠线索时写「暂无依据」。判断依据、接话幅度与各方向理由放入「分析」，不为填模板猜测心理。25–75 覆盖材料不足、自动记录、连续反馈、边界、交流时机、直接问题、交流深度、见面顾虑、共情表达及接梗；76–81 检验魔趣法则的适用与分寸；82–87 检验平衡表达；88–95 检验行为聊法；96–99 检验方向覆盖、边界、普通回应标注、接住玩笑后的态度判断及同一方向的多种表达。以下接话场景默认用于与女性建立或维系恋爱关系，覆盖初识、约会及确定关系后；这不代表对方已表达恋爱好感。场景由用户手工测试，不作为 Skill 运行时引用或自动评测输入。

除明确缺少待回复内容、用户当前决定等关键材料，或方向必须表达用户尚未提供的实际独特感受或个人看法外，首轮不应先要求确认方向、选择方向或追问用户近况。日常共情无需用户预先声明相同感受；确需用户实际感受或看法时只问一个贴合当前聊天的具体问题，不为凑可选方向索取信息。接话建议从「态度、情绪、想法、分析」开始，再逐条写方向、技巧、原则；每个可发送方向通常连续给出 2–3 行「示例回复」，表达空间有限时可只给 1 条，暂不回复固定写「方向：暂不回复」且无需理由或示例。正文可用空行分隔条目，不加标题、开场、结尾或字段外说明。技巧与原则只标实际用于该方向及其每条示例的规则，普通回应写「无专项技巧」，共情、赞美、邀约作为方向而不是技巧。同一方向的示例保留相同接话意图，通过表达方式提供选择，不把换说法拆成多个方向；每条都接住对方实际表达和问题，不编造经历、现实行动、承诺或改变关系的表态；行为聊法的条件式兴趣不写成已做或确定要做。仅分析现有回复效果时直接分析，不套用建议模板或逐条标注。

两个 Skill 都可用时，测试材料可能自动写入 `~/.chat-coach/contacts/`。测试前核对虚构联系人与已有档案没有身份冲突，必要时使用唯一的测试名称；测试后用 `$contact-notes` 明确删除本次创建的测试档案。仅观察接话表现时，可在输入中补充「本轮不记录联系人档案」。
