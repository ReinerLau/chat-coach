## 一致性约定

- 两个 Skill 可单独安装，运行所需说明放在各自目录内，链接不指向仓库外层或另一个 Skill。
- 调整存储位置、文件名与联系人 ID、身份匹配顺序、同名或多账号区分、微信会话 ID 确认条件时，同步核对两份内部说明。
- 完整文件格式在联系人记录 Skill 内维护；调整名称、身份线索或背景分区时，同步检查中文回复教练 Skill 的读取说明能正确理解已有档案。
- 中文回复教练 Skill 读取背景并按已发现的 Skill 名称和路径联动；联系人记录 Skill 负责全部档案写入，支持显式请求及回复流程内自动记录。联动通过当前环境发现结果定位，不添加跨目录运行引用；缺少联系人记录 Skill 时仍能独立回复。
- 中文回复教练 Skill 的回复流程涵盖分析判断、行动建议、心态梳理和拟写，均可按新材料联动记录。模型的分析判断与行动建议不入档；原则、技巧、原文及方法踩坑点在中文回复教练 Skill 自身目录维护，方法踩坑点仅在用户明确要求长期记录时保存。
- 自动联动的信息筛选标准、范围、来源和日期、去重、打算与既成事实的区分、个人观察，以及用户不记录、修正和删除要求的优先级，在两个 Skill 的内部说明中保持兼容。按信息对后续交流的作用筛选增量，互动按重要事件保存；普通闲聊没有新增背景、偏好、约定等有参考价值的信息时跳过。自动保存成功时静默，普通聊天不自动触发；历史意愿不能作为示例回复中用户当前的行动、表态或承诺。
