# 联系人档案规则索引

本文供开发者查找规则和核对兼容性，两个 Skill 运行时只读取各自目录内的说明。

| 位置 | 负责的规则 |
| --- | --- |
| [中文回复教练 Skill 的材料读取说明](../skills/chat-reply/references/materials.md) | 联系人档案的存储位置、身份查找、背景读取与使用边界，以及微信历史查询。 |
| [联系人记录 Skill 的档案维护规则](../skills/contact-notes/references/contact-notes.md) | 联系人档案的存储、身份查找、完整文件格式和创建、更新、修正、删除规则。 |

## 一致性约定

- 两个 Skill 可单独安装，运行所需说明放在各自目录内，链接不指向仓库外层或另一个 Skill。
- 调整存储位置、文件名与联系人 ID、身份匹配顺序、同名或多账号区分、微信会话 ID 确认条件时，同步核对两份内部说明。
- 完整文件格式在联系人记录 Skill 内维护；调整名称、身份线索或背景分区时，同步检查中文回复教练 Skill 的读取说明能正确理解已有档案。
- 中文回复教练 Skill 只读取背景；联系人记录 Skill 按用户明确请求维护档案。历史意愿与个人观察的使用边界保持一致。
