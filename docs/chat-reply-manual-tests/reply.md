## 接话

### 01 回答店名

```text
$chat-reply 小周。帮我想想怎么接下面的聊天。先把她问的事情回应清楚。
背景：小周是我正在约会的女生。店名是街角的白桦咖啡，位置在图书馆旁边。
本轮不记录联系人档案。

聊天记录：
小周：你上次说的那家店是哪家来着？我想周末去看看
```
