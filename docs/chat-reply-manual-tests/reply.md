## 接话

### 01 先接内容

```text
$chat-reply 小周 --intent 接话 --principle 先接内容 --context "小周是我正在约会的女生。店名是街角的白桦咖啡，位置在图书馆旁边。"
本轮不记录联系人档案。


聊天记录：
小周：你上次说的那家店是哪家来着？我想周末去看看
```
