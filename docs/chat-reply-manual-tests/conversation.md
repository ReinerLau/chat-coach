## 连续交互与记录

### 40 只给联系人

```text
$chat-reply 小林
本轮不记录联系人档案。
```

### 41 连续改写

```text
$chat-reply 帮我回小林，轻松一点。我们刚认识不久，我还在公司。
本轮不记录联系人档案。

聊天记录：
小林：今天提前下班了，正在等地铁
```

```text
还是刚才小林这条消息，再短一点，给我两句不同的。
```

### 42 只分析现有回复

```text
$chat-reply 帮我看看给小林写的这句有什么问题，先分析，不用重写。
本轮不记录联系人档案。

聊天记录：
小林：我今天不太想聊工作的事
我还没发出去的回复：那你明天再说说你们项目吧
```

### 43 未收录的技巧

```text
$chat-reply 我想回小许，这次请用“未收录技巧示例”技巧。
本轮不记录联系人档案。

背景：我们正在了解彼此，之前聊过逛书店的事。
聊天记录：
小许：城西那家书店周末有夜场，听说有不少旧书
```

### 44 普通不满意反馈

```text
刚才这句我不满意，像在替她解释心情。还是回应她说的事情，重新写两句。这次只是改写。
```

### 45 明确记录踩坑点

```text
把刚才这个问题记到这次使用的技巧文档里：我只说了想看看电影，你给的回复却替我承诺了周六陪她去。这个场景里我还没确定时间，别把我的兴趣写成已经确定的安排。
```

### 46 联系人记录联动

```text
$chat-reply 帮我回复小林。我们是今年九月朋友介绍认识的，之前一起逛过一次书店，她在杭州工作。

聊天记录：
小林：这两周我在准备资格考试，考完再约吧
```

### 47 聊天中提到技巧名称

```text
$chat-reply 帮我回小林，按下面的聊天直接接一句就好。
本轮不记录联系人档案。

聊天记录：
小林：今天健身教练让我练平衡，站了几秒就晃了
```

### 48 直接问怎么回

```text
$chat-reply 阿澄这句怎么回？
本轮不记录联系人档案。

背景：我们正在约会，平时会互相开玩笑。
聊天记录：
阿澄：你上次找路把我们带到反方向，还说是地图的问题
我：地图确实有点绕
阿澄：嗯，地图还替你走错了两个路口
```

### 49 普通回复请求

```text
$chat-reply 帮我回小林，给两句不同的。我还在公司，今天也加班了。
本轮不记录联系人档案。

背景：我们正在约会，平时会互相开轻松的玩笑。
聊天记录：
小林：终于改完稿了，老板今天像是舍不得让我走
```

### 50 单独了解有哪些技巧

```text
$chat-reply 我不知道有什么聊天技巧可以用，也没有具体要回复的人。先用容易理解的话介绍一下你这里有什么、各自能做什么，不用写回复。
```

### 51 选择依据不完整

```text
$chat-reply 小许刚说“你真讨厌”，我没贴前面的聊天。扩大冲突适合吗？还是该选别的技巧？拿不准的地方先问我。
本轮不记录联系人档案。
```

### 52 没有合适技巧的场景

```text
$chat-reply 小许这样说，我该怎么回？
本轮不记录联系人档案。

背景：小许是我最近在了解的女生，她刚发来下面这条消息。
聊天记录：
小许：我已经说过不想继续聊了，请不要再联系我。
```

### 53 了解之后再比较

```text
刚才介绍的扩大冲突和魔趣法则有什么区别？先解释区别，我还没有具体要回复的消息。
```

### 54 只查看技巧名称

```text
$chat-reply 你这里有哪些已收录的聊天技巧？这次只列名称，不用解释。
```
