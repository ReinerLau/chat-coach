# 联系人记录 Skill

仅通过 `$contact-notes` 显式调用。独立维护背景时，无需确认回复的用户意图。

## 处理流程

1. **明确操作**：根据用户请求确定查看、记录、修正或删除；未说明具体操作时，简短询问要查看或记录什么。查看请求只读取，明确的修改请求直接执行。
2. **定位联系人**：读取[联系人档案共用规则](../../docs/contact-notes.md)，按其中的身份线索查找档案；身份不清或存在同名候选时先澄清。记录请求找不到档案时，可在联系人身份明确后新建；查看、修正或删除请求找不到档案时，告知用户并确认对象。
3. **执行并核对**：按共用规则修改用户指定的信息，保留其他内容；读取保存结果，确认修改落在正确联系人档案，再简短反馈。写入失败时说明失败，不能声称已保存。

用户明确请求记录的背景和互动才写入档案；仅为本轮回复提供的材料不自动保存。仅删除指定条目，明确要求删除整个联系人档案时才删除文件。

同轮显式调用 `$contact-notes` 和 `$chat-reply` 时，先完成记录，再按中文回复教练 Skill 处理回复；联系人身份或记录内容仍待澄清时，先解决该问题。仅调用本 Skill 时，完成记录或查看即可。
