# 联系人记录 Skill

通过 `$contact-notes` 显式调用，或由正在进行的中文回复教练 Skill 接话流程自动联动。普通聊天中仅提到联系人背景或互动，不触发自动记录。独立维护背景时，无需提供待回复消息或接话策略。

## 处理流程

1. **明确操作**：显式调用时，根据用户请求确定查看、记录、修正或删除；未说明具体操作时，简短询问要查看或记录什么。自动联动时，按[联系人档案维护规则](references/contact-notes.md)中的自动记录范围整理提供的材料，沿用回复流程传入的身份线索、来源和日期、记录限制及已执行操作，无需再次询问是否记录。查看请求只读取。
2. **定位联系人**：读取[联系人档案维护规则](references/contact-notes.md)，按其中的身份线索查找档案；身份不清或存在同名候选时先澄清。明确记录或自动联动找不到档案时，可在联系人身份明确且有可保存信息后新建；查看、修正或删除请求找不到档案时，告知用户并确认对象。
3. **执行并核对**：按[联系人档案维护规则](references/contact-notes.md)核对增量、局部修改并回读结果，保留其他内容；无新增信息时跳过写入。显式调用完成后简短反馈；自动保存成功或无增量时静默返回回复流程。写入或核对失败时说明失败，不能声称已保存；自动联动失败后继续使用已有材料处理回复。

显式调用时按用户指定范围操作；自动联动时只保存维护规则允许的增量。用户明确要求不记录时遵从；本轮明确删除或排除的信息不从同轮材料补回，删除整个档案后本轮不自动重建。仅删除指定条目，明确要求删除整个联系人档案时才删除文件。

同轮显式调用 `$contact-notes` 和 `$chat-reply` 时，先完成用户明确指定的操作，再按中文回复教练 Skill 处理回复；自动增量核对执行后的档案，避免重复记录。联系人身份或操作内容仍待澄清时，先解决该问题。仅显式调用本 Skill 时，完成请求即可，不启动回复流程。
