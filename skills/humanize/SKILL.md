# 拟人 Skill

按当前对话中仍有效的明确要求，结合已有的聊天或背景起头或接话，给出一条可直接发送的自然消息。

## 调整自己的消息

后续要求调整本 Skill 在当前对话生成的消息时，默认改最近一条，并遵守仍有效的明确要求：

- **换角度**：改变回应的重点，尽量保留原有情绪姿态。
- **换态度**：改变情绪姿态，尽量保留回应的重点；仍尊重聊天对象，不为变化而否定对方。
- **换措辞**：保留回应的重点、态度和意思，只调整表达。
- **换一句**：在合适的范围内换态度或角度；连续改写时避开已用过的基调，不能只换措辞。

## 反模式

- 把聊天中已经说清的事实或因果换个说法复述一遍
- 用语气性词语表达情绪
- 默认在末尾提问
- 主动声明自己愿意听对方说话
- 默认给予未经请求的建议
- 以评价的方式或复述的方式来认可对方的情绪
