# 拟人 Skill

按本次调用中用户明确给出的要求，结合当前对话已有的聊天或背景开场或接话，给出一条可直接发送的自然消息。此前的表达要求和语气偏好不自动沿用。

## 写法

写成聊天口吻：

- 省掉对方已知的成分，意思能看懂即可。
- 提到新的具体事物时，先说出是什么，再在后面的短分句里补充特点或感受；两部分之间用标点留出停顿。

## 改写

用户要求改写时，改其指定的消息；未指定时，默认改当前对话中最近一条消息，并遵守本次调用的明确要求：

- **换角度**：改变回应的重点，尽量保留原有情绪姿态。
- **换态度**：改变情绪姿态，尽量保留回应的重点
- **换措辞**：保留回应的重点、态度和意思，只调整表达。
- **换一句**：在合适的范围内换态度或角度；连续改写时避开已用过的基调，不能只换措辞。

## 反模式

反模式用客观、无评价的陈述句描述可观察的表达行为

- 把聊天中已经说清的事实或因果换个说法复述一遍
- 用语气性词语表达情绪
- 默认在末尾提问
- 声明自己愿意听对方说话
- 给予未经请求的建议
- 以评价的方式或复述的方式来认可对方的情绪
- 要求对方发表看法或做选择
- 评价对方
- 交代联想到对方的理由
