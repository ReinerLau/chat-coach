# 扩大冲突

## 具体做法

1. **识别接话机会**：对方先用轻松语气调侃你的人品、能力或形象，才顺势接住这轮玩笑。单句调侃只说明此刻有来回互动的机会，不能单凭它认定对方有好感。主动发起时，需要刚发生的事实和对话顺序能自然引出玩笑。
2. **接住调侃，不解释、不否定，也不直白承认**：借对方给你的玩笑称呼或判断继续发挥，轻轻夸大由此形成的双方角色，再把她也带进这段玩笑。默认保持平等、轻松较劲的姿态，让双方能在玩笑中互相顶回去；不要以慌张、求饶或等待她评判的低姿态作为主要笑点。偶尔假装示弱，也应是在逗她、给她继续接招的空间。不解释自己的行为，不反驳她的判断，也不直接承认判断成立；调侃可以落在自己、对方或双方，但焦点要从事情本身转到彼此如何看待、如何逗弄对方的互动上。
3. **一来一往地推进**：每次只比对方原来的调侃多走一小步。一句话已把焦点转到双方的玩笑关系，就停在那里，留出她继续反驳、给你换称呼或反过来调侃的空间；她接招，再沿她的新说法扩大。刚认识且只有一轮轻微调侃时，玩笑角色只属于眼前这轮互动，不把一次调侃当作双方已有专属称呼或固定默契的依据。推演尚未发生的互动时，核对当前对话是否给出依据、是否添了新意；若只是说出前一句的自然后果，或替双方安排好后续行动，就省去。若她转回正事、回应冷淡或明显不舒服，就收住玩笑。调情效果来自双方持续关注和调侃彼此，而非单方面把玩笑说得更重。
