# 技巧库规则

已收录技巧是本文件同级 `techniques/` 下的独立 Markdown 文档。目录不存在或没有文档时，技巧库为空。介绍、推荐或使用技巧前，读取相关条目；不得凭名称、旧版本记忆或仓库外的书籍文件补写要求。

## 选择与输出

- 用户只问技巧清单时列出已收录名称；询问用途或差异时读取对应条目后回答。
- 根据场景推荐时，核对条目的适用条件和容易误用之处，只推荐一个符合当前已知材料的技巧。不能确认关键前提时说明不确定性或询问该项事实；没有合适条目时直接说明。
- 用户指定技巧时按该条目的具体做法提炼要求。即使用户记不清用法，也不把旧版本或模型记忆当成已收录内容。
- 技巧要点写明本轮交流动作、具体做法、已知事实与适用边界，不复制来源中的示例为真实聊天。教练输出到要点为止。

## 收录与修正

仅在用户明确要求维护技巧库时操作。每项技巧保存为 `techniques/技巧名称.md`，包含以下四节；首次收录时再创建目录：

```markdown
# 技巧名称

## 适用条件

## 具体做法

## 容易误用之处

## 来源
```

依据用户提供的材料或可读取的来源提炼可执行要点，保留原材料中的前提和例外；`来源` 写明实际书名与章节、链接或用户提供的说明，不编造出处。材料不足以确定做法时指出缺口，暂不收录。用户明确要求修正或删除时只改指定条目；修改后回读并核对链接。仓库中新增、重命名或删除条目时同步更新根目录 README 的“可用技巧”清单；独立安装的 Skill 不依赖 README。正常使用时不扫描 EPUB。
