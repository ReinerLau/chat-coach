# 关系层级：从初识到确认关系的互惠判断

## 定位与来源

《魔鬼约会学》“男追女的分层升级理论”把交往描述为搭讪关系、认识关系、普通朋友关系、好朋友关系、男女朋友关系。本指南保留其观察关系进展的角度，改用适用于双方的说法。它是作者的经验框架，不是亲密度评分、经过验证的阶段定律，也不是必须逐级完成的流程；不列入“已收录技巧”。

这里判断的是**双方目前做到了什么、是否愿意继续**。它与[交流三层次](交流三层次：试探交流意愿与关系判断.md)观察谈话中交换了什么、[三三法则](三三法则：初识联系节奏与邀约判断.md)讨论初识联系节奏不同。能聊到感受，不等于已成为“好朋友”；聊了三轮，也不等于关系升级。

## 书中五层与可观察线索

| 书中名称 | 可观察的互动 | 不能单凭此认定 |
| --- | --- | --- |
| 搭讪关系：即时交谈 | 双方愿意在当前场景短暂交流 | 愿意交谈不等于愿意留联系方式或继续发展 |
| 认识关系：取得联系方式 | 双方同意有后续联系的渠道，并实际有来往 | 给了联系方式或回复一次，不等于有恋爱兴趣 |
| 普通朋友关系：单独约见 | 双方接受并落实单独见面，见面后仍愿意交流 | 一次约会不等于已是朋友、排他约会或伴侣 |
| 好朋友关系：更持续的双向了解 | 双方较稳定地主动联系、分享近况或感受，能讨论需求与分歧 | 一次倾诉、热情回应或身体接触不等于亲密承诺 |
| 男女朋友关系：确认伴侣关系 | 双方明确讨论并认可关系性质、期待与边界，行动与约定相符 | 单方表白、默认称呼或亲密行为不能替代共同确认 |

这些名称是书中的叙述顺序，并非所有关系都会经过相同路径。现实关系可能发展更快、停留、退回或不以伴侣关系为目标；不要替任何一方宣布其所处层级。

## 如何用于判断下一步

1. **先看持续行为**：分开记录双方谁发起、谁回应、是否兑现约定、能否尊重边界。将明确表达与实际行动一起看；单次简短回复、延迟回复或一次积极互动都保留其他解释。
2. **再提出一个可拒绝的下一步**：若有交流空间，可提出一次与当前关系相称的联系、见面或确认期待的请求。说明自己的意图，允许对方拒绝或提出替代；不把接受某一步解释为同意下一步。
3. **按反馈调整**：有持续互惠再深入；证据不足时保持未知，长期只有单方投入时降低投入。明确拒绝发展、表示不适或要求停止联系时收住，不用书中的层级继续推动。

书中关于“回复次数足够就能升级”、按性别规定交流方式、以身体接触代替确认的说法，不作为判断标准。给用户建议时说明可见证据、关键未知及一个低压力的下一步，不保证关系会按层级发展。
