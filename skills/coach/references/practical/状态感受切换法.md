# 状态感受切换法

1. **找到安全的起点**：关系初期想主动破冰，或想自然接住对方的话时，优先从当前材料里的具体情境或对方已经提到的内容入手；没有可用的个人细节时，也可从轻量的第一人称日常状态入手。对方需要明确答复或正在谈严肃的事时，先回应当下内容。
2. **从状态切到自己的浅层感受**：先说当前材料支持的现象，或自己正在做、刚做的小事，再接一层轻的感受，让对方能从小事或感受继续聊。自己的日常状态和浅层感受可按教练 Skill 的个人素材规则创作，不与已知事实冲突；不替对方判断情绪。
3. **按回应逐轮切换**：每轮只写一条消息，给对方接话的空间。对方接住后，再沿新内容引出下一组相关的状态和感受；确实需要对方回答时才提问。对方没有接话，或明显不愿继续时收住，不连续发送自述来填补冷场。

## 具体写法

例句只说明写法，不当作实际聊天材料。场景：关系初期，你与刚认识的人在室内等活动开始；窗外的雨突然变大，你觉得雨声让自己放松。

> - 反例：“外面下大雨了。你觉得怎么样？”
> - 正例：“窗外的雨一下大了，听着还挺放松。”
>
> 反例只报告天气，再把续聊压力交给对方；正例把眼前的变化接到自己的浅层感受上，对方可以接雨，也可以接这种感受。
