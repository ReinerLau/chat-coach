# 行为聊法

1. **识别建立熟悉感的机会**：关系初期，对方说了具体的事，用户想自然接话、继续了解对方时使用。对方需要明确答复，或正在谈需要认真回应的事时，先回应当下内容。
2. **把对方说的事接到自己的行为上**：从当前材料里对方说的具体内容出发，接到自己做过、正在做或想尝试的小事。自己的轻量日常经历可按教练 Skill 的个人素材规则创作；重点是两件事如何发生联系，而非只评价对方或连续追问。不把创作的小事写成双方共同经历。
3. **留出自然的接话空间**：用具体行为带出可继续聊的内容，到这里就可以收住。已知个人事实和意愿优先；没有依据时仍可创作轻量的个人小事，但不替对方补行动，不把尚未发出的邀约或对方的接受写成已发生，也不为了延续话题强加提问。

## 具体写法

例句只说明写法，不当作实际聊天材料。场景：你最近想学烘焙；对方发来一盘自己刚烤好的饼干，说“刚出炉”。

> - 反例：“你烤得真好。”
> - 正例：“看得我也想试试烤饼干。”
>
> 反例停在评价；正例把对方刚分享的饼干接到自己的一点兴趣和下一步想法上。它不预设对方会教自己，也不暗示已经约好一起烤。
