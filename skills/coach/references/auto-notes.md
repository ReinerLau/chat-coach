# 自动记录联动

本说明用于教练 Skill 正在进行的回复流程，涵盖关系与互动分析、行动建议、心态梳理、制定表达要求及其间连续补充材料时。回复流程结束或转为其他任务后，停止自动记录。

## 联动流程

1. **整理增量**：从用户说明、贴出的聊天和本轮为理解场景或补齐事实而查到的微信历史中，筛选会影响以后理解联系人、接话、邀约或跟进的信息：背景、明确偏好与边界、重要事件及反馈、约定、当前情况和用户明确提供的个人观察。互动按重要事件提取结果和必要背景；普通寒暄、玩笑、饮食闲聊或简短应答未带来上述信息时，跳过保存。只使用实际取得的内容，不为记录额外查询历史或复制聊天全文；已有档案内容用于核对，不作为新材料重复入档。
2. **交给联系人记录 Skill**：有可保存信息时，从当前环境已发现的 Skill 中按名称 `contact-notes` 找到入口，使用其提供的路径读取 `SKILL.md`，按它的内部引用执行。传入联系人身份线索、相关材料及来源和日期、用户的记录限制，以及同轮已执行的记录、修正或删除操作；由它定位档案、核对增量、保存并回读。无需向用户请求再次调用或逐条批准自动记录；联动路径来自当前发现结果，不硬编码安装位置或跨目录引用。
3. **继续回复流程**：保存核对完成，或核对后没有新增信息时，继续回复流程；若回复目标或身份仍待澄清，先询问，已确定时结合真实材料和用户当前的自然语言要求回复。用户补充新材料或再次查询取得新材料后，重复以上流程；单纯调整表达要求或重复材料，不要求写入。

## 记录边界与异常

- 联系人身份明确且有可保存信息时，可由联系人记录 Skill 新建档案。身份不明、同名或信息冲突无法解释时，先澄清需要记录的对象或内容；澄清前不猜测写入。
- 用户明确要求不记录时，按其指定的内容或时间范围跳过保存。本轮明确删除或排除的信息，不从同轮材料再次补回；删除整个档案时，本轮也不自动重建。
- 表达要求、回复目标、所用原则或技巧、原文和方法踩坑点、模型的分析判断与行动建议不入档。方法踩坑点按教练 Skill 自身的文档维护说明处理。用户的打算与已发生的互动分开理解；只有用户明确说明已发送、已发生，或实际微信历史能证明的内容，才作为已发生的互动记录。
- 同轮显式调用两个 Skill 时，先执行联系人记录 Skill 的明确操作，解决相关身份或内容歧义后再进入回复流程；自动联动仅补充尚未保存且未被排除的信息。
- 自动保存成功或无增量时默认静默，直接继续回复流程。缺少或无法读取联系人记录 Skill 时，在当前连续回复交互首次需要保存时简短提示安装或可用性问题，继续使用已有材料回复；教练 Skill 不自行维护档案。写入或核对失败时简短说明失败，继续回复，不声称已保存。
