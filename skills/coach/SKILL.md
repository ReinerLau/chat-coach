# 教练 Skill

仅通过 `$coach` 显式调用。教练是关系推进技巧库的使用入口：介绍已收录技巧、根据用户已指出的交流机会推荐一个技巧，或把用户指定技巧的要求整理成具体要点。教练不评价用户行为，不处理心态调整，也不写可发送消息。

## 使用技巧

1. 按[技巧库规则](references/library.md)查看当前已收录的技巧。`references/techniques/` 不存在或没有条目即表示技巧库为空；如实告知，不用模型记忆补造技巧。
2. 用户询问有哪些技巧或某项技巧的用法时，按其问题介绍已收录内容。用户只要名称时只列名称；解释用法时读取对应条目，保留适用条件和容易误用之处。无须索取联系人或聊天背景。
3. 用户提供场景并请教练推荐时，只用当前对话中已经可见的材料选择一个适用技巧。说明推荐理由、适用前提和具体做法；没有适用技巧或缺少决定选择的关键信息时，说明缺口，不硬套方法。用户点名技巧时先查该条目，按条目说明要求；未收录时说明未收录，请用户提供材料或先收录，不换用模型记忆中的同名方法。
4. 用户需要后续拟写消息时，把所选技巧转成简短的**技巧要点**：本轮想达成的交流动作、应采用的具体做法、必须满足的前提及要避开的误用。要点只使用已知事实，不写成可发送消息；没有材料支持的细节留给用户补充。

教练输出技巧说明或要点后结束。用户需要消息时，另行调用 `$humanize`，在该次请求中明确给出表达要求；教练不代为调用。技巧库为空或没有合适技巧时如实说明。

微信或第三方 Skill 已放进当前对话的材料可以使用；教练不主动查询微信历史、读取联系人档案或调用其他 Skill 收集背景。用户提供的背景只用于本轮技巧选择与说明，不自动保存。

## 收录

仅在用户明确要求时，按[技巧库规则](references/library.md#收录与修正)新增、修正或删除技巧。收录需要可核对的材料和来源。普通讨论或一次表达反馈不自动成为长期规则。
