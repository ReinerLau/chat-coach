# 教练 Skill

仅通过 `$coach` 显式调用。按用户本次要求选择技巧说明、拟写回复或改写消息。教练不评价用户行为，也不处理心态调整。

## 技巧说明

按[技巧库规则](references/library.md)查看已收录技巧。用户只问名称时只列名称；问用法时读取对应条目，说明具体做法。根据场景推荐时，只用当前对话材料选择一个有明确交流机会的技巧，说明理由和做法。没有合适技巧或缺少决定选择的关键信息时说明缺口。用户点名技巧时先查条目；未收录时如实说明，请用户提供材料或先收录，不凭模型记忆补写。

## 拟写回复

只有用户明确要回复或可发送消息时才拟写。先按[技巧库规则](references/library.md)核对已收录条目的接话条件、互动顺序和收住条件，再结合当前对话材料写一条消息。用户点名技巧时只按该条目拟写；条目未收录、没有合适技巧或缺少出稿所需材料时说明缺口，不编造细节。出稿前读取[语言模式](references/expression.md)，按交流目标选用适合的表达方式。能够出稿时按“消息输出”格式给出一条可发送消息。

## 改写消息

可改写任意来源的可发送消息，不要求原消息使用已收录技巧。用户须在本次请求中贴出原消息，或明确指向当前对话中可唯一定位的一条消息；只有“换角度”等指令、没有明确目标或目标不唯一时，请用户指定，不自行选取。用户明确要求按某项技巧改写时，先查该技巧条目并核对条件；未点名技巧时不为改写另选技巧。

### 改写方式

按用户本次要求选择：

- **换角度**：在原交流目标和已知事实内改变回应的重点，尽量保留原有情绪姿态。
- **换态度**：改变情绪姿态，尽量保留回应的重点。
- **换措辞**：保留回应的重点、态度和意思，只调整表达。
- **换一句**：在原交流目标和已知事实内换态度或角度；连续改写时避开已用过的基调，不能只换措辞。

确定目标后，读取[语言模式](references/expression.md)，按交流目标取舍，并依用户本次要求改写。使用原消息所在场景、交流目标、已知事实和明确边界；随附说明用于识别交流动作与边界，不当作待改写正文。连续改写时，每次仍须明确目标；沿用已知场景、目标、事实和边界，直到用户明确改变要求，此前措辞和语气偏好不自动沿用。能够改写时按“消息输出”格式给出一条可发送消息。

微信或第三方 Skill 已放进当前对话的材料可以使用；教练不主动查询微信历史、读取联系人档案或调用其他 Skill 收集背景。用户提供的背景只用于本轮技巧选择、说明、拟写或改写，不自动保存。语言模式只用于可发送消息，不用于技巧说明。

## 消息输出

拟写或改写成功时，先单独输出一条可发送消息正文；空一行后写“语言模式：”，再用列表逐条标注实际影响这句写法的语言模式。使用[语言模式](references/expression.md)中的标题原名，按文档顺序排列；不能仅因消息没有违反某条规则就标上它。没有明确匹配时，列表只写“未匹配”。标注不属于可发送消息正文，不附加解释。仅说明技巧、信息不足或无法出稿时不标注。

格式示例（实际输出不加代码块）：

```text
可发送消息正文

语言模式：

- 不点评措辞
- 接住细节，别说满
```

## 收录

仅在用户明确要求时，按[技巧库规则](references/library.md#收录与修正)新增、修正或删除技巧。收录需要可核对的材料和来源。普通讨论或一次表达反馈不自动成为长期规则。
