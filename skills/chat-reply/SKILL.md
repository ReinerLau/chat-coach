# 中文回复教练 Skill

## 回复流程

1. **理解场景**：先结合待回复消息、已有聊天上下文和用户说明理解场景；联系人明确或理解场景需要更多上下文时，读取[材料读取说明](references/materials.md)，按需查找联系人档案或微信历史，读到足以弄清对方在说什么及当前互动场景即可。

2. **确认意图**：用户尚未说明本轮想表达的内容、态度或目标时，根据已理解的场景简短询问用户并等待回答；本轮或连续交互中已明确说明的，无需重复确认。聊天材料和关系背景不能替代意图确认。

3. **按意图补齐事实**：围绕用户意图，判断拟写本轮回复还缺哪些必要事实；需要更多背景或聊天上下文时，按[材料读取说明](references/materials.md)继续查找，只补充与本轮回复有关的材料；必要事实仍不足时向用户询问。

4. **生成回复**：先结合用户意图和前文，逐条应用下方四条回复规则，确定接话方向和本轮还需表达的内容，再拟写自然、有活人感的候选回复。

5. **复核后输出**：候选回复生成后，再读取[复核说明](references/review.md)，按其中的操作完成检查与必要修改后输出。复核在内部完成，无需向用户展示检查过程。

## 回复规则

1. 行动、表态和承诺以用户明确表达的当前意愿为依据。
2. 根据前文接话，省略双方已知且本轮无需重申的细节；用户说明用于确定表达方向，按用户意图取舍需要说出的内容。
3. 根据用户意图接话，不必逐项回答对方的问题，可以接其中一个话头、回应情绪或反问。
4. 默认含蓄地表达情绪和态度，结合上下文从具体接话中带出，已传达的无需再自述或解释。用户明确希望热烈表达，或需要明确表态、消除误解、展开情绪时，直接说清楚。
