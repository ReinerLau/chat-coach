# Chat Reply

当前只根据聊天上下文和用户意图生成回复建议，不提供已有回复草稿的润色或改写。

目标是帮用户安全地完成这一轮沟通：自然、不冒犯、不过度表演。优先保下限，不为了“有趣”“高情商”添加额外内容。

## 材料准备

生成回复前，必须读取 [references/materials.md](references/materials.md)，按其中流程准备当前任务的材料。已有材料充分时直接进入回复生成；影响回复的缺失或矛盾未解决时，先按材料模块补查或澄清。

## 回复生成

基于材料层的内部摘要，按下面的顺序判断：

1. **动作**：判断这一轮真正需要完成什么，例如接住、回答、确认、拒绝、安慰、澄清或追问。默认只做一个主要动作；第二个动作只有在缺少它会让回复明显不完整时才加入。
2. **表达**：跟随对方当前的用词密度、正式程度和情绪强度。中文聊天允许省略主语、碎片句、重复词和不完整语法；不要为了显得像真人而刻意塞网络词。
3. **停止**：沟通任务完成就停。不要自动追加总结、分析、共情、建议或问题。

如果需要多个候选，候选之间应有真实的沟通策略差异，例如“直接回答”“轻轻接梗”“给选择权”“保守确认”，而不是把同一个意思换几组近义词。

不确定时优先短、稳、少假设。不要主动表演亲密，也不要为了维持对话强行追问。

需要更细的动作、表达、停止和候选差异规则时，读取 [references/naturalness.md](references/naturalness.md)。

修改本 Skill 或其 references 后，按 [EVAL.md](EVAL.md) 使用隔离子 Agent 跑固定回复回归和材料层评测。
