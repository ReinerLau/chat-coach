# 中文回复教练 Skill

仅通过 `$chat-reply` 显式调用。本轮及连续回复交互中，每次取得用户提供或按需查询的新材料后，先按[自动记录说明](references/auto-notes.md)完成联系人记录 Skill 的联动，再继续意图引导、事实补齐或回复生成；无需用户另行调用 `$contact-notes`。

## 回复流程

1. **理解场景**：先结合待回复消息、已有聊天上下文和用户说明理解场景；联系人明确或理解场景需要更多上下文时，读取[材料读取说明](references/materials.md)，按需查找联系人档案或微信历史，读到足以弄清对方在说什么及当前互动场景即可。

2. **判断并确认意图**：每次新的拟写请求都读取[接话方向引导](references/intent-guidance.md)，先根据对话判断用户意图是否适合当前场景，按其中的固定模板展示判断依据，再确认本次想表达的内容、态度或目标并等待反馈；已说明且适合时简短复述，明显错位时推荐调整，未明确时结合场景引导方向。确认适合场景的方向后进入事实补齐；用户结束探索时停止。模板时机、确认范围与反馈处理见该说明。

3. **按意图补齐事实**：围绕用户意图，判断拟写本轮回复还缺哪些必要事实；需要更多背景或聊天上下文时，按[材料读取说明](references/materials.md)继续查找，只补充与本轮回复有关的材料；必要事实仍不足时向用户询问。

4. **生成回复**：先读取[回复规则](references/reply-rules.md)，结合已确认且适合场景的用户意图和前文逐条应用，确定本轮还需表达的内容，再拟写自然、有活人感的候选回复。

5. **复核后输出**：候选回复生成后，再读取[复核说明](references/review.md)，按其中的操作完成检查与必要修改后输出。逐条复核在内部完成；若复核推翻先前的场景判断，按接话方向引导更新已展示的依据。
