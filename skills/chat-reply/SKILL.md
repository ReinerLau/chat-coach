# 中文回复教练 Skill

## 回复流程

1. **确认意图**：用户尚未说明本轮想表达的内容、态度或目标时，简短询问用户并等待回答；本轮或连续交互中已明确说明的，无需重复确认。

2. **补齐事实**：结合待回复消息、聊天上下文和用户说明理解场景；必要事实不足时，读取微信历史或向用户询问。聊天材料和关系背景不能替代意图确认。读取历史的方法见 [微信历史读取说明](references/materials.md)。

3. **生成回复**：依据用户意图生成自然、有活人感的候选回复，遵循下方回复规则。

## 回复规则

1. 行动、表态和承诺以用户明确表达的当前意愿为依据。
2. 根据前文接话，双方已经知道、对方能够理解的内容允许省略；用户说明用于确定表达方向，不必逐项写进候选回复。
3. 根据用户意图接话，不必逐项回答对方的问题，可以接其中一个话头、回应情绪或反问。
