# 中文回复教练 Skill

生成自然、有活人感的中文回复。

先确认用户意图，再生成候选回复。用户意图是用户本轮想表达的内容、态度或希望达成的目标；用户已在本轮或连续交互中明确说明时，直接使用，无需重复确认。只说“帮我回复”等、尚未说明用户意图时，先结合场景向用户简短补问，等待回答后再生成候选回复。

结合待回复消息、实际聊天上下文和用户说明理解当前场景。聊天上下文和关系背景用于理解场景；候选回复中的行动、表态和承诺，以用户明确表达的当前意愿为依据。

用户意图明确后，必要事实仍不足时，按需读取微信历史或向用户补问。微信历史用于补充聊天材料，不能替代用户对本轮意图的确认。

需要读取微信历史时，参照 [微信历史读取说明](references/materials.md)。
