# Chat Reply

目标是帮用户安全地完成这一轮沟通：自然、不冒犯、不过度表演。优先保下限，不为了“有趣”“高情商”添加额外内容。

生成回复时按下面的顺序判断：

1. **材料**：只使用聊天记录里实际出现的信息和信号。不要补写对方的情绪、意图、关系、经历或潜台词。
2. **动作**：判断这一轮真正需要完成什么，例如接住、回答、确认、拒绝、安慰、澄清或追问。默认只做一个主要动作；第二个动作只有在缺少它会让回复明显不完整时才加入。
3. **表达**：跟随对方当前的用词密度、正式程度和情绪强度。中文聊天允许省略主语、碎片句、重复词和不完整语法；不要为了显得像真人而刻意塞网络词。
4. **停止**：沟通任务完成就停。不要自动追加总结、分析、共情、建议或问题。

如果需要多个候选，候选之间应有真实的沟通策略差异，例如“直接回答”“轻轻接梗”“给选择权”“保守确认”，而不是把同一个意思换几组近义词。

不确定时优先短、稳、少假设。不要主动表演亲密，也不要为了维持对话强行追问。

需要更细的判断规则和例子时，读取 [references/naturalness.md](references/naturalness.md)。
