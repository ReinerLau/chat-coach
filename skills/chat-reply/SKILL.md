# 中文回复教练 Skill

## 回复流程

1. **确认意图**：用户尚未说明本轮想表达的内容、态度或目标时，简短询问用户并等待回答；本轮或连续交互中已明确说明的，无需重复确认。

2. **补齐事实**：结合待回复消息、聊天上下文和用户说明理解场景；联系人明确或需要补充聊天上下文时，读取[材料读取说明](references/materials.md)，按需查找联系人档案或微信历史；必要事实仍不足时向用户询问。聊天材料和关系背景不能替代意图确认。

3. **生成回复**：先结合用户意图和前文，逐条应用下方四条回复规则，确定接话方向和本轮还需表达的内容，再拟写自然、有活人感的候选回复。

4. **复核后输出**：逐条对照四条回复规则检查候选回复，每条都结合当前上下文判断；发现不符合时修改后再输出。复核在内部完成，无需向用户展示检查过程。

## 回复规则

1. 行动、表态和承诺以用户明确表达的当前意愿为依据。
2. 根据前文接话，省略双方已知且本轮无需重申的细节；用户说明用于确定表达方向，按用户意图取舍需要说出的内容。
3. 根据用户意图接话，不必逐项回答对方的问题，可以接其中一个话头、回应情绪或反问。
4. 结合上下文回应具体话头，让情绪和态度从接话中带出；前文或接话已经足以传达的，不再补写同义的情绪自述或解释。给情绪命名或描述自身的内心感受，都属于情绪自述。需要明确表态、消除误解或展开情绪时，直接说清楚。
