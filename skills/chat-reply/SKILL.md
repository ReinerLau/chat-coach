# 中文回复教练 Skill

仅通过 `$chat-reply` 显式调用。用户参考接话方向，自行选择、修改并发送实际回复；本 Skill 不发送消息。本轮及连续交互中，每次取得用户提供或按需查询的新材料后，先按[自动记录说明](references/auto-notes.md)完成联系人记录 Skill 的联动，再继续判断场景或提供方向；无需用户另行调用 `$contact-notes`。

## 接话流程

1. **理解场景**：结合待回复消息、相邻聊天、关系背景和用户说明理解对方此刻在表达什么。联系人明确或现有材料不足以判断时，按[材料读取说明](references/materials.md)查找相关档案或微信历史，读到足以判断本轮接话即可。缺少待回复内容等关键材料且无法按需取得时，先询问；不为提供可选方向而索取用户的经历或近况。

2. **判断并输出方向**：每次新的接话建议请求都读取[接话方向引导](references/intent-guidance.md)，按其中的「态度、情绪、想法」三行模板展示有依据的交流线索，再直接给出适合当前关系和时机的接话方向。每个可发送方向附一条示例回复；暂不回复的方向无需示例。用户提出的接法可作为场景材料，但方向仍由实际对话决定，不要求用户先确认或选择。

3. **根据反馈调整**：用户要求继续、换方向、改示例或补充新材料时，结合最新上下文直接调整并输出；新材料改变判断时更新三行模板。仅询问现有回复效果时直接分析。用户表示暂停或结束时停止引导。
