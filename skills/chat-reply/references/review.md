# 聊天审查规则

拟写或调整示例回复前，结合关系、上下文和对方此刻的表达，检查所选意图的每条示例；本规则只审查表达，不选择其他意图。仅分析现有回复效果、没有拟写新回复时无需读取。

- **连续提问**：是否连续索取信息，却没回应对方给出的内容？对方主动倾诉时，适度追问可以帮助其展开；事实问题仍直接回答。提问不是默认结尾。
- **只问不说**：若长期只有询问，且话题适合互通信息，可加入有依据的用户状态、感受或想法；不强迫每条自我披露，也不虚构经历或行动。
- **情感过度**：感受、好感或关系表态是否超出当前交往程度？删减无关细节，保留适度的真实表达。
- **时机不合**：末条消息与当前时间、话题是否相称？已结束的旧话题不硬续；问题、求助或约定仍待处理时先回应。
- **忽略交流幅度**：对方仅礼貌回应、敷衍、准备结束或已明确拒绝时，不持续推进或越过边界。不要由单次反应推断关系升级。
- **评价或定义对方**：不直接评判对方的情绪、意愿、能力、性格、外貌、风格或行为，也不以这类判断为前提发问；赞美意图也用具体事实和用户自己的反应表达。

先尝试在所选意图内改写风险表达，核对事实、当前意愿和边界；表达空间有限时减少示例数量。只有所选意图与可见场景明显冲突，才按[通用接话约束](intent-guidance.md)说明依据并请用户决定是否改选。不要为了满足清单强加提问、自我披露或情绪表达。
