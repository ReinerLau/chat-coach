# 示例检查

拟写或调整示例回复时，核对是否回应当前目标、符合用户要求，以及事实、态度、行动和承诺是否有材料依据。本轮未采用具体方法时，直接按自然语言要求检查；采用了用户指定或 Skill 根据场景推荐的方法时，结合已读原文上下文和对应踩坑点检查是否贴合当前场景。缺少关键材料或要求有实质冲突时，说明具体缺口并询问。

通常提供 2–3 条可直接发送且表达有区别的示例，空间不足时可少给。每条只写聊天文本，不加“示例回复”前缀、方向清单、分析字段、原则或技巧标签。技巧推荐及理由与示例文本分开说明；用户只要聊天文本时省略说明。用户要求进一步解释时，书中观点与当前场景的判断分开表达，原文出处应可核对。用户自行决定是否采用、修改及何时发送。
