# 候选回复复核

本文件在候选回复生成后读取。以[回复规则](reply-rules.md)为判断依据，按以下顺序复核。

1. **回看材料**：回看原始聊天、本次已确认的用户意图及[接话方向引导](intent-guidance.md)中的场景判断，确认本轮需要表达的内容仍适合对方当前表达和明确边界。用户分享的近况、经历、感受和看法须有用户说明或实际聊天记录依据，区分过去经历与当下状态；必要事实不足时返回事实补齐，不编造用户信息。
2. **逐条判断**：逐条对照回复规则，结合材料判断候选回复是否符合；发现问题时，定位具体片段及其上下文依据。
3. **尝试删减**：对疑似重复、补充解释或没有实际接话作用的片段，比较保留与删去后的回复。删去后是否损失接话作用、必要信息或用户希望表达的态度？据此决定保留、删除或改写。已知细节可以用于感谢、强调或澄清，不能仅因前文出现过就删除。
4. **回查修改**：修改后重新对照回复规则和场景判断检查最终候选回复，确认发现的问题已解决，且适合场景的用户意图仍完整表达。若发现方向本身明显错位或触及对方边界，返回接话方向引导，更新已展示的判断模板，不输出该候选回复；合格回复直接通过。

全部回复规则均已检查、发现的问题均已处理后，才输出最终候选回复。逐条复核过程留在内部；场景判断依据按接话方向引导的模板展示。
