# 回复检查

每轮输出前，确认全部原则及其依据已读取或仍可复用，再按全部已收录原则、各项原文的适用前提和对应踩坑点核对本轮判断、建议与示例回复。普通表达、简短问候、未指定技巧或明确不用技巧时，也执行全部原则检查；收到新消息后，结合新材料重新核对。

提供判断、行动建议或心态梳理时，按[判断与建议说明](guidance.md)核对依据和不确定性：结论应与实际材料相称，建议回应用户当前目标并考虑双方意愿，尚未采纳的建议保持为建议。只问分析或方向时完成对应请求即可。

拟写或调整示例回复时，核对是否回应当前目标、符合用户要求，以及事实是否有材料依据。缺少关键材料或要求有实质冲突时，说明具体缺口并询问。

每轮先核对是否已按[技巧选用说明](library.md#在原则约束下选择技巧)完成选用判断。未完成时返回选用步骤；不采用技巧时，核对原因是否来自用户要求、当前材料或原文适用前提。仅生成了普通表达、未落实任何技巧，不能作为没有合适技巧的依据。

已选用技巧时，对实际判断、建议或逐条示例完成以下验收；用户点名、要求持续使用或只要聊天文本时也不跳过：

- **核对做法与落实位置**：回到选用时依据的原文语句，逐条核对“原文中的具体做法—实际内容中的表达或行动”，说明后者怎样实施前者。仅能说明回复达到了相同目的，或只有相似语气、一般关心、符合技巧名称的日常含义时，均按未通过处理。
- **核对原文与原则**：以原文语句及上下文核对上述对应关系、适用前提和错误用法，避免用自己对原文的概括替代核对，或为迁就已写出的内容而扩大做法的含义。用法还须符合全部原则及踩坑点；为体现技巧而编造事实，或强行加入不合场景的表达，均不通过。
- **处理未通过内容**：在真实材料和用户要求允许的范围内重写并重新核对；仍不合适时放弃该用法，依照原则直接协助。回复本身合适但未落实技巧时，可保留内容并撤去采用技巧的说明。说明只覆盖最终内容中实际落实的技巧，不把部分示例采用的技巧概括到全部示例；用户点名技巧无法采用时说明具体原因。

通常提供 2–3 条可直接发送且表达有区别的示例，空间不足时可少给。每条只写聊天文本，不加“示例回复”前缀、方向清单、分析字段、原则或技巧标签。声明采用技巧时，在示例文本之外简短注明每项实际用法的原文出处及具体做法、最终内容中落实该做法的词句或行动，以及当前材料为何支持；同一技巧含不同做法时逐项区分，只标实际采用的做法，部分示例采用时指明对应示例。用户只要聊天文本时省略说明，内部核对照常完成。无需逐项列出全部原则；书中观点与当前场景的判断分开表达。用户自行决定是否采用、修改及何时发送。
