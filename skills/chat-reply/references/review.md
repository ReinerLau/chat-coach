# 候选回复复核

本文件在候选回复生成后读取。以 [SKILL.md 中的回复规则](../SKILL.md#回复规则)为判断依据，按以下顺序复核。

1. **回看材料**：回看原始聊天和已明确的用户意图，确认本轮需要表达的内容。
2. **逐条判断**：逐条对照回复规则，结合材料判断候选回复是否符合；发现问题时，定位具体片段及其上下文依据。
3. **尝试删减**：对疑似重复、补充解释或只渲染语气的片段，比较保留与删去后的回复。删去后是否损失接话作用、必要信息或用户希望表达的态度？据此决定保留、删除或改写。已知细节可以用于感谢、强调或澄清，不能仅因前文出现过就删除。
4. **回查修改**：修改后重新对照回复规则检查最终候选回复，确认发现的问题已解决，且用户意图仍完整表达。合格回复直接通过。

全部回复规则均已检查、发现的问题均已处理后，才输出最终候选回复。复核过程和判断依据留在内部。
