# 状态感受切换法

## 适用与表达

适合分享用户自身近况且与当前话题自然相连时，先说一个有依据、可观察的状态（现象或用户自己的行为），再接一个轻量的主观感受或看法。例如用户提供天气和路上见闻时，可写“早晨路上跑步的人特别多，看得我也有点跃跃欲试”。发起话题模式也可依据用户提供的近况使用。状态是用户自己的材料，不把对方的状态、联系人档案或模型推测写成用户经历；感受和看法可以拟作候选表达，不等于确认了用户真实感受。

## 分寸

先回应对方当前内容。诉苦、求助或直接提问时，先处理处境、需要或问题；用户近况确有联系且不会转移焦点时才补充。对方表明边界、准备结束或不愿继续时，不借此换话题。缺少必要的用户状态时先问一个具体问题，不虚构状态；可在已有材料内写出时不额外索取。状态加感受是表达结构，**不要求向对方提问**，更不要求以问题收尾；对方没有接话时，不连续堆叠状态和感受。
