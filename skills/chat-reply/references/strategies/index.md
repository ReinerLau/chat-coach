# 策略

策略是意图、原则与技巧的命名组合。使用 `--strategy` 选择一套策略时，不能同时使用 `--intent`、`--principle` 或 `--technique`。只点名意图时使用同名策略；“轻松共情”须显式选择。组合的机器可读来源为 [策略清单](catalog.json)。

| 策略 | 意图 | 原则 | 技巧 |
| --- | --- | --- | --- |
| 接话 | 接话 | 先接内容、事实有据、尊重边界、把握分寸、不评价对方 | 无 |
| 起头 | 起头 | 无 | 无 |
| 共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致 |
| 轻松共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致、夸张引申 |
| 赞美 | 赞美 | 具体赞美 | 无 |
| 邀约 | 邀约 | 先理解顾虑 | 无 |

策略及自定义组合须遵守意图的允许项清单。每条示例都须体现所有选定技巧；场景不适用时说明原因，请用户改选，不自动删项。旧名称“普通回应”无效。
