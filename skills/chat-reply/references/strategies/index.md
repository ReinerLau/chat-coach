# 策略索引

策略是本轮交流（回应消息或主动开场）采用的接法。用户可用 `$chat-reply <联系人名> --strategy <正式策略名>` 指定下表中的一项，也可在含义明确的自然语言请求中点名正式名称。未点名时默认“普通回应”，不按聊天内容自动推荐其他策略；“安慰她”“轻松一点”“高情商回复”等普通描述以及“平衡表达”“魔趣聊法”等旧称不自动映射。只读取本轮采用的策略文档，不遍历其他策略文档，也不额外补用未点名的策略。

“普通回应”是项目自定义项，也是未点名正式策略时的默认项。输出不出现“技巧”“原则”标签。自然语言明确点名多个策略时只组合点名项；如果表达要求互相抵触，说明冲突并请用户取舍，不自行拆成其他策略。所有策略都受[通用接话约束](../strategy-guidance.md)和[聊天审查规则](../review.md)约束。明确边界、事实与行动依据、直接问题和时机是通用约束，不是供模型自动加入的策略。
