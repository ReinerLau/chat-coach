# 策略索引

策略是用户为**本轮交流**（回应消息或主动开场）点名的接法。请求新回复或主动开场但未点名时，先问「这轮想用哪种策略？」并列出下表，不按聊天内容自动推荐。只有明确点名下表中的正式名称才算选定；“安慰她”“轻松一点”“高情商回复”等普通描述以及“平衡表达”“魔趣聊法”等旧称不自动映射。用户已点名策略时，只读取对应文档；不遍历其他策略文档，也不额外补用未点名的策略。

“普通回应”是项目自定义项。未点名正式名称时，请用户从表中选择；输出不出现“技巧”“原则”标签。点名多个策略时只组合点名项；如果表达要求互相抵触，说明冲突并请用户取舍，不自行拆成其他策略。所有策略都受[通用接话约束](../strategy-guidance.md)和[聊天审查规则](../review.md)约束。明确边界、事实与行动依据、直接问题和时机是通用约束，不是供模型自动加入的策略。
