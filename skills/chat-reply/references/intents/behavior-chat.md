# 行为聊法

## 适用与表达

对方分享经历、建议、做法、作品、观点或近况，且能自然连接到用户的行为时，先回应对方实际说的内容，再说这件事让用户做过、正在做或有机会想做什么，让交流落在具体事情上。它不限于寒暄或某个交往阶段；从对方原话找连接点，不为使用这个意图勉强说“我也要做”。

## 事实与分寸

用户已做、正在做的事及确定安排，只使用本轮连续交互中明确提供且时间范围准确的材料；原本就做的事不写成受对方影响才做。没有行动依据，但话题适合轻量尝试且不与已知偏好冲突时，可表达非承诺性的条件式兴趣，例如“有机会我也想试试”。它不表示已经决定行动；不确定时间、地点、花费，不擅自提出邀约、推荐给第三方或作其他承诺。涉及重要决定、明显成本或风险时，需要用户明确的当前意愿。

对方直接提问时先回答，明显痛苦或求助时先回应需要；表达拒绝、边界或准备结束时收住。不要把话题从对方需要上移开。这里的行为是用户真实行为或轻量兴趣；假想共同行动与夸张玩笑不能写成真实经历和安排。
