# 邀约

## 适用范围

本意图沿用现有线下见面邀约场景：**对方回应见面邀约时，表示担心尴尬、冷场等情况**。它用于理解顾虑、回应反馈及在双方意愿明确时继续商量见面，不扩展为一般性的邀约开场或约会方案。以真实聊天为依据，不把书中对担心原因的解释当成对方真实心理。

## 理解顾虑

“可能尴尬”是对方已表达的担心，既不是答应见面，也不必然是拒绝。对方说出具体原因，例如怕话少被误认为不好相处时，可贴近原话试探性核对并回应；推测出的其他原因须等对方确认。只有“怕尴尬”而无原因时，先承接担心，可轻问见面的哪部分让她在意；不预设害怕被评价，也不急着提出时间地点。提问是可选方式，不是每条示例必需。

## 回应与分寸

对方已说出或确认具体顾虑时，回应其在意之处。可表达用户对见面或当前交流的感受与意愿；现实行为和承诺仍以用户当前提供的信息为准。不要用“保证不会尴尬”、催促适应或直接缩短见面时间代替理解。对方明确愿意见面、用户当前仍想邀请时，才可商量具体时间地点；只用已知安排，不替用户承诺。对方仍犹豫或提出再等等时放慢邀约；明确不想见、拒绝或要求停止时尊重决定，不继续劝说。
