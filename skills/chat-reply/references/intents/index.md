# 意图索引

意图是用户为**当前待回复消息**点名的接法。新回复请求未点名时，先问「这轮想用哪种意图接话？」并列出下表，不按聊天内容自动推荐。只有明确点名下表名称、兼容旧称或无歧义的简称才算选定；“安慰她”“轻松一点”“高情商回复”等普通描述只是用户说明，不自动映射。用户已点名意图时，只读取对应文档；不遍历其他意图文档，也不额外补用未点名的意图。

| 意图 | 兼容旧称 | 文档 |
| --- | --- | --- |
| 共情 | 共情原则 | [共情](empathy.md) |
| 赞美 | 赞美原则 | [赞美](praise.md) |
| 邀约 | 邀约原则 | [邀约](invitation.md) |
| 平衡表达 | 平衡原则 | [平衡表达](balance.md) |
| 行为聊法 | — | [行为聊法](behavior-chat.md) |
| 状态感受切换法 | — | [状态感受切换法](state-feeling-switch.md) |
| 扩大冲突 | 扩大冲突技巧 | [扩大冲突](expand-conflict.md) |
| 魔趣聊法 | 魔趣法则 | [魔趣聊法](moqu-chat.md) |
| 普通回应 | — | [普通回应](ordinary-reply.md) |

“共情”“魔趣”等能够唯一指向表中意图的明确简称可以识别；含糊的说法仍请用户点名。旧称只是输入兼容，输出不出现“技巧”“原则”标签。点名多个意图时只组合点名项；如果表达要求互相抵触，说明冲突并请用户取舍，不自行拆成其他意图。所有意图都受[通用接话约束](../intent-guidance.md)和[聊天审查规则](../review.md)约束。明确边界、事实与行动依据、直接问题和时机是通用约束，不是供模型自动加入的意图。
