# 意图

意图说明本轮示例回复要完成的交流行为，只能选一项。正式名称为：`接话`、`共情`、`赞美`、`邀约`、`起头`。没有明确意图时以`接话`兜底；聊天材料中的词语不算用户选定意图。

| 意图 | 目标与适用范围 |
| --- | --- |
| 接话 | 根据对方待回复内容及其后用户已发内容继续交流；话题已经自然结束时不硬续。 |
| 共情 | 对方表达感受、诉苦或轻度抱怨时，回应其具体处境与感受。 |
| 赞美 | 用户要肯定对方的具体行为，或表达由此产生的感谢和感受。 |
| 邀约 | 仅处理对方回应线下见面邀约时提出的尴尬、冷场等顾虑；不扩展为一般邀约开场。 |
| 起头 | 用户主动开启交流，以本轮提供的近况或近期真实互动作为切入点。 |

意图只确定交流目标，不自动附加原则或技巧。只点名一个意图且没有单项原则、技巧时，读取[同名预设](../presets/index.md)；点名单项时按显式组合执行。`起头`缺少真实切入点、`邀约`缺少对应顾虑等关键材料时，说明具体缺口，不编造场景。
