# 意图

意图说明本轮要完成的交流行为，一轮只选一个；未指定时以“接话”为默认意图。只点名意图且没有单项时，有同名预设则使用该预设，否则只选择意图。每个意图目录的清单明确允许哪些原则和技巧；公共目录中的项目也须列入该清单才能使用。

| 意图 | 目标与适用范围 | 规则 |
| --- | --- | --- |
| 接话 | 根据待回复内容继续交流；话题已结束时不硬续。 | [接话](reply/index.md) |
| 共情 | 回应对方具体处境与感受。 | [共情](empathy/index.md) |
| 赞美 | 肯定对方具体行为及用户由此产生的感受。 | [赞美](praise/index.md) |
| 邀约 | 仅回应线下见面邀约后的顾虑。 | [邀约](invitation/index.md) |
| 起头 | 以真实近况或近期互动主动开场。 | [起头](opening/index.md) |

缺少意图所需的关键材料时说明缺口，不编造场景。
