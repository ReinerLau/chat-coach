# 平衡表达

## 适用与表达

用户希望表达有依据的肯定或真实愿望，而对话中有自然转折时，可在正向表达之后接一个与本轮事情直接相关、用户当前明确提供的现实限制，或指向自己的轻微玩笑，调节语气。先把真正要表达的积极意思说清楚，转折只是轻轻一笔；单纯报出安排，不自动构成平衡表达。

## 分寸

现实限制必须真实且与当前话题有关。自嘲只借用用户已说明的自身习惯或处境，不能贬低对方、索取安慰或掩盖真实兴趣。没有合适转折时，不编造障碍；若用户要求一定使用这种表达而缺少必需的现实信息，先问一个具体事实。对方直接问看法或安排时，先给明确答案，再决定是否加转折。用户提出虚假限制来显得不那么积极时，保留其真实兴趣和安排。
