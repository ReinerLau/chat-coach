# 魔趣聊法

## 适用与表达

当前话题适合轻松表达，并有当前聊天或双方已知真实互动作为联系点时，先接住对方实际说的内容，再用有联系感、明显是假想的夸张动作增添趣味。联系感让用户与对方处在同一可想象的情境；动作要有画面感，但不写成现实行为或即将实施的计划。这个意图可以单独点名；点名后无需再选择另一方向。若用户同时点名扩大冲突，仍须满足扩大冲突对对方先发起轻度调侃的条件。

## 分寸

不能用玩笑代替回答直接问题、回应身体不适、明显痛苦、求助或尊重明确边界。对方准备结束时，不用夸张表达强留话题。共同经历、现实行动和承诺必须有用户当前提供的依据；感受和看法可作候选表达。按交往程度和对方反应控制亲近程度，不从一句轻松回应推断好感。只够自然表达事实或感受时，不硬套假想动作；缺少真实联系点时先问所需材料，不编造共同经历。
