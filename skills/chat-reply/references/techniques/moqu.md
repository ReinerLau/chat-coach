# 魔趣法则

本技巧用于润色已选定方向中的一条轻松示例回复，通过有联系感的夸张行为增添趣味；它不另成一个方向，也不要求每轮使用。可与扩大冲突技巧结合，但接梗方向不依赖这两种技巧；对方表达情绪时，先按共情原则判断要接住什么，再考虑表达方式。

联系感来自当前聊天或双方已知的真实互动，让用户与对方在同一情境中产生关联；行为是可以想象的动作，夸张使它明显属于假想或玩笑。先接住对方实际说的内容，再看这种表达是否自然。只够表达事实、感受或直接回答问题时，就使用自然的普通说法，不硬套“状态＋感受”或固定模板。

玩笑不代替回应直接问题、身体不适、明显痛苦、求助或明确边界；对方准备结束交流时也不以夸张表达强留话题。示例中的共同经历、用户真实感受、现实行动和承诺仍以用户当前明确提供的材料为准；假想行为要让人看出是玩笑，不写成即将实施的安排。根据交往程度和对方反应控制趣味与亲近程度，不凭一句轻松回应推断好感或关系升级。
