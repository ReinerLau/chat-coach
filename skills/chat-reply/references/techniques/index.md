# 技巧索引

先按[接话方向引导](../intent-guidance.md)选择接话方向，再依当前消息、相邻互动及关系背景读取适用的技巧。技巧只在确实用于接话或示例时标注；不为填标签读取全部技巧或增加方向。

- 对方分享的内容能自然连接到用户做过、正在做或有机会想做的事时，读取[行为聊法](behavior-chat.md)，判断行为回应是否适合当前交流；不限于寒暄。
- 当前话题适合分享用户自己的近况，或用户明确要求主动开场时，读取[状态感受切换法](state-feeling-switch.md)，判断是否适合用用户自己的状态和浅层感受延续交流；它只润色已有方向，不单独增加方向。
- 对方先发起轻度调侃，且当前互动或关系背景显示双方能互相开玩笑时，读取[扩大冲突](expand-conflict.md)，判断接梗方向是否适合用夸张地维护自己的角色。接梗是方向；只有示例实际运用扩大冲突时才标为技巧。
- 已选定的方向适合轻松表达，且材料提供真实的双方联系点时，读取[魔趣法则](moqu.md)，判断是否适合把一条示例写得更生动；它不是独立接话方向，只在示例确实使用有联系感的夸张假想行为时标为技巧。
