# 行为聊法

当对方分享经历、建议、做法、作品、观点或近况，且这些内容能自然连接到用户的行为时，可用行为聊法作为接话方向。它不限于寒暄或某个交往阶段：先回应对方实际说的内容，再说这件事让用户做过、正在做或有机会想做什么，让交流落在双方可继续谈的具体事情上。只有这一接话点与其他方向有实质区别时才单列，不为使用技巧而添加方向。

从对方原话中找具体连接点。用户已做或正在做的事，以及确定要做的安排，只使用当前连续交互中用户明确提供、时间范围准确的材料；行为并非因对方而起时，不写成受对方影响才做。若用户没有提供行动依据，但话题适合轻量尝试、又不与已知偏好或处境冲突，可表达非承诺性的条件式兴趣，例如「有机会我也想试试」。这种说法不表示用户已经决定行动；不擅自确定时间、地点或花费，不提出邀约、向第三方推荐或其他承诺。涉及重要决定或明显成本、风险时，仍需用户明确的当前意愿。

对方直接提问时先回答；明显痛苦或求助时先回应处境与需要；表达拒绝、边界或准备结束交流时按其意思收住。行为回应若会把话题从对方需要上移开，就选更贴合的方向。对方的内容只能引出空泛评价或勉强的「我也要做」时，自然接住具体内容即可。

行为聊法说的是对方内容与用户实际行为或轻量兴趣的联系。共情原则中的「行为一致」用假想共同行动表达同一阵线；魔趣法则用明显夸张的假想动作增添趣味。三者可以按场景各自使用，不把共情或玩笑误写成真实经历与行动安排。
