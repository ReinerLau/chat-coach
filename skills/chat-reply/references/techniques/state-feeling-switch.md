# 状态感受切换法

状态感受切换法用于在合适的话题中分享用户自己的近况，让对方容易接话。先选择与当前话题相关的安全内容，说一个可观察到的状态（现象或用户自己的行为），再补充一个轻量的主观感受或看法。例如，用户提供了天气和路上见闻时，可以写「早晨路上跑步的人特别多，看得我也有点跃跃欲试」。它是示例表达技巧，不单独构成接话方向。

适用于对方态度允许继续交流、当前话题能自然连接到用户近况的场景；用户明确要求主动开场时，也可据其提供的近况使用。状态必须有当前连续交互中用户明确提供的事实依据，不能从联系人档案、模型推测或对方的状态推导为用户经历。感受和看法可作为候选表达，不代表已确认是用户真实感受。若该方向必须依赖用户尚未提供的状态，按接话方向引导中的规则询问；已有其他合适方向时不为使用本技巧额外索取信息。

先回应对方当前的内容。对方诉苦、求助或提问时，先接住其处境、需要或问题；只有用户的近况与话题确有联系、分享不会转移对方关注时，才考虑在回应后补充。对方表达边界、准备结束交流或态度显示不愿继续时，不用本技巧换话题或延长对话。对方没有接话时，根据其后续态度决定是否收住，不连续堆叠状态和感受来维持聊天。

只有示例实际采用用户自身的「状态＋感受」结构时，才标注「技巧：状态感受切换法」。不把回应对方状态或猜测对方感受标成此技巧；不为填标签而使用固定句式。
