# 交流层次判断方法

本方法用于填写接话判断中的「态度、情绪、想法」三行。借用《魔鬼沟通学》的三个交流层次，从当前消息及相邻互动找可见线索，判断本轮适合怎样接。三层不是必须依次推进的步骤；一条消息也可能同时包含几层，没有依据的层次写「暂无依据」。

## 态度交流

观察对方此刻给出多少继续交流的空间。书中从热情到恶毒的六级态度可作参考，只描述消息表现；不要求每轮定级，也不把级别写成联系人的属性：

| 态度表现 | 可见线索 | 接话判断 |
| --- | --- | --- |
| 热情 | 主动展开内容，并把用户带入后续交流，例如邀请一起做某事。 | 可顺着共同话题或邀约回应；行动和承诺仍核对用户当前意愿。 |
| 友好 | 给出具体状态、细节或感受，让对方有话可接。 | 接住具体内容或感受，可自然延续；深入仍看具体内容。 |
| 礼貌 | 回答明确但简短，暂未主动延展。 | 可轻接已有话头；连续如此时简短交流、适时收住。 |
| 敷衍 | 回复明显敷衍，几乎不提供可接的内容；单次也可能构成线索。 | 礼貌收住或暂停，不靠追问、换话题推进。 |
| 冷漠 | 持续没有回应或明确不接话。 | 不追加催促；未回应的原因不明时，不推断对方态度。 |
| 恶毒 | 出现辱骂、驱赶等明确排斥交流的表达。 | 尊重停止交流的边界，只考虑必要的收住或不回复。 |

这些级别不等于关系深浅或对用户的好恶。单条简短回复或一次未回应本身不足以定级；若内容和语境已显示礼貌以下的信号，就按本轮信号收住，不等待多轮重复。对方当时是否忙碌、表达习惯等也可能影响表现。结合关系背景理解，但以当前对话为准；只依据可见材料判断此刻适合怎样接。

## 情绪交流

看对方是否明确说出或通过当下叙述流露自己的高兴、难过、委屈、担心等感受。对方主要在表达感受时，可先接住其具体处境和感受；若同时提出问题，也要回应问题。只回应材料能支持的感受，不替对方诊断或编造情绪。

## 想法交流

看对方是否提出观点、判断、选择、计划，或邀请用户交换看法。对方主要在讨论这些内容时，回应其具体想法或问题；需要表达用户自己的意见、选择或承诺时，以用户提供的当前意愿和事实为准。交换想法不要求赞同对方，也不等于替对方做决定。

情绪和想法可能同时出现；既不因讨论想法而略过明显的感受，也不因出现情绪而回避对方明确提出的问题。对话能否深入还取决于双方回应，不把进入更深层级当作目标。
