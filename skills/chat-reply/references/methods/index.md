# 场景方法索引

先按[接话方向引导](../intent-guidance.md)判断本轮交流空间和方向，再依当前消息、相邻互动及关系背景读取适用的方法。这里只决定何时读取；方法的用法和边界以各自文件为准。不为凑方向或修饰每条示例而读取全部方法。

- 对方表达情绪时，读取[共情方法](empathy.md)，按处境和情绪轻重选择表达方式。
- 当前内容有具体可赞美的细节，或用户提出想赞美对方时，读取[赞美方法](praise.md)，判断是否适合赞美及其强度。
- 对方分享的内容能自然连接到用户做过、正在做或有机会想做的事时，读取[行为聊法](behavior-chat.md)，判断行为回应是否适合当前交流；不限于寒暄。
- 对方先发起轻度调侃，且当前互动或关系背景显示双方能互相开玩笑时，读取[扩大冲突（接梗）方法](expand-conflict.md)，判断是否适合顺着原话接梗。
- 对方回应见面邀约时表达尴尬、冷场等顾虑，读取[邀约方法](invitation.md)，先理解顾虑，再判断是否适合继续商量见面。
- 已选定赞美方向，或用户当前确实想与对方一起做事，且正向表达适合轻松说出时，读取[平衡的艺术](balance.md)，判断能否用真实限制或轻微自嘲调节示例的语气；它不是独立接话方向。
- 已选定的方向适合轻松表达，且材料提供真实的双方联系点时，读取[魔趣法则](moqu.md)，判断是否适合把一条示例写得更生动；它不是独立接话方向。
