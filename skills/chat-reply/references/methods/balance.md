# 平衡的艺术

本原则适用于已选定的赞美方向，或用户当前确实想与对方一起做事的方向。示例保留有依据的赞美或愿望，再用真实限制或指向自己的轻微玩笑调节语气；它不另成接话方向，也不要求对方先调侃。

先接住对方实际说的内容，再看正向表达是否符合用户当前意愿和交往程度。限制只使用用户已说明的时间、安排等事实；自嘲要明显是玩笑，不写成新的经历、处境或感受，也不贬低对方。若没有自然的平衡点，直接表达即可，不为显得从容而编造障碍、制造稀缺感或索取对方夸奖。平衡不是固定句式，也不应把真实的兴趣说成无所谓。

对方直接问看法或安排时，先回答问题；对方诉苦、身体不适、求助、拒绝或要求停止时，按其处境和边界回应。对方接受玩笑或配合安排，只说明这一轮交流顺利，不据此推断好感或加大表达强度；下一轮继续看实际反馈。
