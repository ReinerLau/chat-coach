# 共情方法

本方法用于对方表达情绪时选择合适的共情表达方式。

日常轻度抱怨中，双方已知处在同一情境时，可优先通过行为一致来认可对方：让示例回复中的用户加入对方想做或不想做的事，用轻量的假想共同行动表达同一阵线。例如两人各自在冬天早晨起床，对方说不想上班，可接「咱先假装没听见闹钟」。这种示例无需用户先声明有相同感受，但不能与用户已知的态度或生活情况冲突；只有对方身处该情境时，不写成两人在一起或有相同经历。

若双方平时能接这种玩笑，还想进一步释放情绪，可把一致行动夸张引申到明显荒谬的结果，例如「咱俩先赖着，让被窝替我们去打卡」。夸张的是共同处境，不是嘲弄对方；这是可选接法，不要求每次共情都升级玩笑。

行为一致要让用户参与其中。单纯换句话复述、用「确实很辛苦」一类评注认可情绪，或只顺着话头开玩笑，都不等于表达行为一致；「确实」本身并非禁用词。对方明显痛苦、明确求助或提出问题时，先认真回应具体处境、请求或问题，不强行安排共同动作或玩笑。

假想共同行动只用于表达共情，不写成现实行动、计划或承诺。
