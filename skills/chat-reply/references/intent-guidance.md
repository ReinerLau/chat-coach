# 接话方向引导

用户尚未明确用户意图（包括表示脑子空白、不知道接什么）时，按以下流程帮助用户找到想说的内容。用户已有明确且仍适用的用户意图时，直接继续主流程。

## 提供方向

1. **找接话点**：回看当前聊天，识别可接的具体细节、情绪和话题，结合已有关系背景判断哪些适合本轮接话。评价、共情、玩笑、分享等可作为思考线索，实际方向围绕这段聊天组织。
2. **精选方向**：优先提供 3–4 个有材料依据、内容明显不同的方向，差异体现在接话点或想表达的内容与态度，而不只是同一句话换语气。材料只支持较少方向时，按实际数量提供。
3. **配短示例**：每个方向用简短说明交代“接哪一点、想表达什么”，配一句自然的短示例；展示前读取并应用[回复规则](reply-rules.md)。示例用于帮助用户辨认偏好，经历和事实以已有材料为依据，行动、表态和承诺以用户明确表达的当前意愿为依据。需要用户补充的信息先留在方向说明中，待选定后询问。
4. **等待反馈**：用简短的话告诉用户可以选择、组合、修改或排除方向，然后等待回答。此时方向与示例都是供用户考虑的建议，经用户认可的部分才成为用户意图。

## 根据反馈推进

- **选定或组合**：用户选中方向、组合方向，或自行说清想表达的内容后，直接进入主流程的“按意图补齐事实”，再生成候选回复。选择已经明确时无需再次确认；组合中有实质冲突时，只询问冲突部分。
- **部分认可或修改**：保留用户认可的接话点、内容与态度，围绕不满意的部分调整。修改后的要求已经足以拟写时直接继续主流程；仍未明确时提供调整后的方向并等待反馈。
- **全部否定或仍不知道**：结合刚才的方向和用户反馈，问一个具体、容易回答的问题，帮助辨别不满意的原因。例如用户觉得玩笑都不合适，可以问“你更想关心她现在累不累，还是聊客户到底要怎么改？”问题围绕当前聊天，允许用户用自己的话回答；收到反馈后，按明确程度进入上述“选定或组合”或“部分认可或修改”分支，避开已排除的部分。
- **没有新增偏好**：用户回答“不知道”时，换一个贴近聊天的具体切入点，给少量短示例帮助比较，再等待反馈；后续探索保留已有选择和排除项。
- **结束探索**：用户表示先不回、不想继续或暂停时，停止引导。

以用户已经明确本轮想说的内容、态度或希望达成的目标为完成条件，不设固定探索轮数。必要事实仍缺失时，在主流程中补齐；聊天材料、历史意愿和模型推荐不能代替用户本轮选择。
