# 策略预设

策略是意图、原则和技巧的命名预设。`--strategy`只能选下表一项，不能与`--intent`、`--principle`、`--technique`混用。只写一个正式意图且没有单项原则或技巧时，使用对应同名预设；`轻松共情`只能显式点名。未指定意图、原则、技巧和策略时，默认`接话`预设。仅点名原则或技巧、没有意图时，以`接话`预设为基础添加点名项。

| 预设 | 意图 | 原则 | 技巧 |
| --- | --- | --- | --- |
| 接话 | 接话 | 先接内容、事实有据、尊重边界、把握分寸、不评价对方 | 无 |
| 起头 | 起头 | 无 | 无 |
| 共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致 |
| 轻松共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致、夸张引申 |
| 赞美 | 赞美 | 具体赞美 | 无 |
| 邀约 | 邀约 | 先理解顾虑 | 无 |

意图与显式单项原则或技巧同写时，构成自定义组合，不展开同名预设。预设中的所有技巧也必须体现在每条示例中；场景无法支持时说明具体不适用处，请用户改用自定义组合或其他预设，不自动省略。所有原则只在被本表或用户显式参数选中时生效；技巧自身的适用条件始终随技巧生效。`普通回应`不再是预设名。
