# 预设

预设是意图与原则、技巧的命名组合，至少包含一项原则或技巧。使用 `--preset` 选择一套预设时，不能同时使用 `--intent`、`--principle` 或 `--technique`。意图存在同名预设时，该预设为默认预设；意图有多个预设时，其他预设须通过 `--preset` 显式选择。只点名意图时，有同名预设则使用该预设，否则只选择意图。组合的机器可读来源为 [预设清单](catalog.json)。

| 预设 | 意图 | 原则 | 技巧 |
| --- | --- | --- | --- |
| 接话 | 接话 | 先接内容、事实有据、尊重边界、把握分寸、不评价对方 | 无 |
| 共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致 |
| 轻松共情 | 共情 | 非评价式共情、避免比较转移 | 行为一致、夸张引申 |
| 赞美 | 赞美 | 具体赞美 | 无 |
| 邀约 | 邀约 | 先理解顾虑 | 无 |

预设及自定义组合须遵守意图的允许项清单。每条示例都须体现所有选定技巧；场景不适用时说明原因，请用户改选，不自动删项。旧名称“普通回应”无效。
