# 原则索引

先按[接话方向引导](../intent-guidance.md)判断本轮交流空间和方向，再依当前消息、相邻互动及关系背景读取适用的原则。原则用于核对方向与表达的分寸；这里列出读取条件和输出名称，具体边界以对应文件为准。不为填标签读取全部原则或增加方向。

- 每次新的接话建议请求都读取[交流层次判断原则](conversation-levels.md)，据此判断态度、情绪、想法；普通回应或自然收住没有更专项的原则时，可用此名称说明接话幅度。
- 对方表达情绪、适合给共情方向时，读取[共情原则](empathy.md)，按处境和情绪轻重选择表达方式。行为一致是该原则中的表达方式，不单列技巧。
- 当前内容有具体可赞美的细节，或用户提出想赞美对方时，读取[赞美原则](praise.md)，判断是否适合赞美及其强度。
- 对方回应见面邀约时表达尴尬、冷场等顾虑，读取[邀约原则](invitation.md)，先理解顾虑，再判断是否适合继续商量见面。
- 已选定赞美方向，或用户当前确实想与对方一起做事，且正向表达适合轻松说出时，读取[平衡的艺术](balance.md)，判断能否用真实限制或轻微自嘲调节示例的语气；它不是独立接话方向，只在实际采用时标为原则。
- 对方明确拒绝或要求停止时，按[接话方向引导](../intent-guidance.md)标注「尊重边界原则」；示例涉及用户经历、看法、行动或承诺时，按同一引导标注「真实表达原则」。只在这些约束对该方向的选择或示例有具体作用时标注。
