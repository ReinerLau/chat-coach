# 交流层次判断原则

本原则用于判断接话建议中的「态度、情绪、想法」，判断依据与接话幅度写在随后「分析」字段。借用《魔鬼沟通学》的三个交流层次，从当前消息及相邻互动找可见线索，判断本轮适合怎样接。三层不是必须依次推进的步骤；一条消息也可能同时包含几层。态度字段只写六级标签之一，依据不足时只写「无法定级」；情绪或想法没有依据时写「暂无依据」。

## 态度交流

观察对方此刻给出多少继续交流的空间。有足够依据时，在「态度」一行明确标出下列六级之一；依据不足时写「无法定级」。级别只描述本轮消息表现，不是联系人的属性或对用户的好恶：

| 态度表现 | 可见线索 | 接话判断 |
| --- | --- | --- |
| 热情 | 主动展开内容，并把用户带入后续交流，例如邀请一起做某事。 | 可顺着共同话题或邀约回应；行动和承诺仍核对用户当前意愿。 |
| 友好 | 给出具体状态、细节或感受，或结合上下文积极接住当前玩笑。 | 可接住已有内容自然延续；即使只接住笑点、没有新话题，也可就此收住。 |
| 礼貌 | 回答明确但简短，暂未主动延展。 | 可轻接已有话头；连续如此时简短交流、适时收住。 |
| 敷衍 | 回复明显敷衍，几乎不提供可接的内容；单次也可能构成线索。 | 礼貌收住或暂停，不靠追问、换话题推进。 |
| 冷漠 | 持续没有回应或明确不接话。 | 不追加催促；未回应的原因不明时，不推断原因或长期态度。 |
| 恶毒 | 出现辱骂、驱赶等明确排斥交流的表达。 | 尊重停止交流的边界，只考虑必要的收住或不回复。 |

单条简短回复或一次未回应若缺少足以区分级别的语境，写「无法定级」，并说明已知线索和适合的接话幅度；若单次消息连同上下文已显示敷衍或更明确的排斥信号，就据此定级并收住，不等待重复。持续未回应可标为冷漠，但不猜测原因。对方当时是否忙碌、表达习惯等也可能影响表现。结合关系背景理解，以当前对话为准；级别不等于关系深浅，也不要求为了延长聊天而接话。明确边界无论伴随哪个级别，都按边界收住或暂停。

## 情绪交流

看对方是否明确说出高兴、难过、委屈、担心等当下感受，或通过具体叙述流露出有依据的感受。对方表达感受是情绪线索；双方围绕感受作出回应，才称为已有情绪交流。身体疲惫或事件经过只作为处境，不单凭这些信息替对方命名情绪。对方主要在表达感受时，先接住其具体处境和感受；若同时提出问题，也要回应问题。

## 想法交流

想法涉及对事情的理解、判断、行动理由和打算，也包括能说明这些内容的做法。对方表达看法、理由、选择、做法或计划，是想法线索；双方围绕这些内容具体来回探讨，才称为已有想法交流。单纯报告近况或行为、提出事实性问题，不因此归入想法交流；问题仍须按其内容直接回应。需要表达用户自己的看法、选择、行为或承诺时，以用户提供的当前意愿和事实为准。交换想法不要求观点一致，也不等于替对方做决定。

情绪和想法可能同时出现；既不因讨论想法而略过明显的感受，也不因出现情绪而回避对方明确提出的问题。对话能否深入还取决于双方回应，不把进入更深层级当作目标。
