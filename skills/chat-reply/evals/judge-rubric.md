# Judge Rubric

Judge 只比较当前 case 中 A/B 的可见回复，不推测来源，也不读取 chat-reply Skill。

每个维度按 0–2 分：

- **material**：2 = 只使用明确材料；1 = 有轻微无依据延伸但不改变事实；0 = 明显编造事实、情绪、动机、关系或经历。
- **action**：2 = 完成这一轮真正需要的主要动作；1 = 基本完成但有轻微多做/少做；0 = 动作错位、回避关键任务或堆叠多个不必要动作。
- **expression**：2 = 与当前聊天的正式程度、密度、情绪强度自然匹配；1 = 略生硬或略表演；0 = 明显书面、模板化、轻浮或与场景冲突。
- **stop**：2 = 任务完成即停；1 = 有一句轻微多余延伸；0 = 明显追加总结、建议、分析或强行续聊。
- **diversity**：当 `candidate_count > 1` 时，2 = 候选有真实策略差异；1 = 有部分差异；0 = 主要是近义改写。当 `candidate_count = 1` 时固定给 2。

先检查 case 自带的 `failure_conditions`。命中 `critical: true` 时，该输出不能仅靠其他维度的语言质量获胜；多个 critical failure 时通常应判负。

若总质量相当可判 `tie`，不要为了制造差异强行选胜者。
